# Gallery 导航控件与输入细节验收

在 `bugfix/shadcn` 运行实际 Gallery 示例。脚本通过 Avalonia 输入路由命中控件、移动指针、按住、拖动和释放，取样记录布局、颜色与选择值。

| 验收项 | 结果 |
| --- | --- |
| ColorPicker Basic，圆角下的颜色可达性 | Luma 浅色 261 × 159 DIP 色板，直接点击矩形右上角内侧命中 `PART_InputTarget`，得到 S=1、V=0.9997。捕获拖动到右上端点得到 S=V=1、`#006AFF`，到左上得到纯白，两个底角均为纯黑。右上端点的圆圈在 `(247.5,13.5)` DIP 显示，释放保持 RGB。颜色框的 HEX 路径另确认能设置精确的 `#006AFF`。 |
| OTP 八位连排第六格左边框 | Luma 浅、深色实际 Gallery 中，旧悬停格左接缝沿用左邻格普通边色。修复后复用了同一条 1 DIP 线的位置，左右边分别统一为浅色 `#454545`、深色 `#B9B9B9`。第一格聚焦时悬停、按下、离开，以及显式分隔符和半透明实例覆盖均复测。桌面定向 67 项通过。 |
| TabStrip / TabControl 的 Card 标签 | Shadcn Card 外角最高 8 DIP，原本较小的圆角继续使用，接内容区的一边为直角。Luma 浅深色 Disabled 与 Draggable 场景检查了上下左右四种位置、悬停、选中和禁用。48 帧中标签尺寸与边框厚度一致，Line 标签的对照像素一致。已完成桌面定向 283 项。 |
| Panel Steps | Luma 的 Filled 中号与 Outlined 小号，首尾由 26 DIP 收至 8 DIP，中间角为零。2× Skia 浅深色中，两排高分别为 71、60 DIP，两个箭头的边界和布局一致，鼠标点击第二步仍切到索引 1。浅色 Filled 有 32 个箭头斜边抗锯齿像素差异，其余三排的两端之间逐像素一致。 |
| Splitter 分隔线与拖拽柄 | 实际 Basic / Horizontal / Resizable Disabled 在 Luma 浅、深色各复跑。修复前浅色静止和悬停的中心柄、分隔线均为 `#F5F5F5`，深色均为 `#262626`，实际鼠标命中已成立。修复后实测中心柄静止 → 悬停 → 拖动为浅色 `#737373 → #3B3B3B → #0A0A0A`、深色 `#A1A1A1 → #CACACA → #FAFAFA`。原始拖拽区宽 6 DIP、高 220 DIP，拖动 32 DIP 后首个面板加宽 32 DIP，悬停位置不动，移出恢复，禁止拖动的分隔处不显示中心柄。 |
| Pagination 焦点裁剪和紧邻的 Go to | Gallery 的 Mini、普通分页和 Simple 页码框复测。Luma 浅色完整焦点环采样为 RGB 227，深色为 42。此前分页根裁去选择器焦点环，快速跳页的内部容器也裁剪输入框焦点环。Mini 中选择器与 Go to 的间距由 2 DIP 调为 3 DIP，与主题环宽相符。原生 Mini 的页面视口、内容范围和滚动偏移保持一致；10→20 每页、Tab 切换、回车跳到第 2 页通过。 |
| ButtonSpinner 按住上、下按钮 | Luma 浅色原 Basic 例的外框为 126 × 36 DIP，手柄分别为 31 × 16.5 DIP。修复前按住时上下各丢失 29 个实色弧线像素，撕裂扫描线分别 25、24 条。把外框边线置于手柄绘制层上后，实色像素损失和撕裂扫描线均为零，底部有 2 个抗锯齿边缘像素变化。按住仍等到释放才单步触发，实测上调四次、下调三次，焦点环保留。 |
| NavMenu inline 整块底色与单行状态 | 实际 macOS 原生 Gallery，展开 Item 2、点击 Option 3、把鼠标移到 Option 4。Luma 浅色展开面从 `#F5F5F5` 变成外层的 `#FFFFFF`，普通面／悬停／选中三色为 `#FFFFFF / #F5F5F5 / #D4D4D4`；深色为 `#0A0A0A / #262626 / #444444`。选中文字对比为 12.09:1、7.73:1。显式 Dark Style 的外层与展开面均为 `#001529`，单行选中继续使用该模式的颜色。 |
| SimplePagination 小号页码输入框 | 实际 Gallery Simple mode 最下方的启用和禁用输入框在 Luma 由 32 DIP 降到 26 DIP，垂直居中后上下各留 3 DIP。数字布局仍为 22 DIP，行和箭头仍为 32 DIP，中号输入仍为 36 DIP。启用态可聚焦和回车跳页，禁用态不接受键盘输入。Ant Design 对照的小号、中号均保持原 24、32 DIP。 |

复核使用 Luma 浅深色。NavMenu 与 Pagination 包含 macOS 原生帧，Steps、Splitter、ButtonSpinner、OTP 接缝及 Card 标签包含 2× Skia 前后对照。SimplePagination 的原生字形逐像素相同，输入框与行的位置符合预期。Gallery 延迟物化后的内容范围估算相差 36 DIP，取证时页码行、可见视口与滚动偏移一致。

清理临时驱动、截图后，定向通过 303 项 Desktop 控件、220 项渲染（复用未受影响的 159 项及最终 Pagination 61 项）、164 项 Shadcn 主题、13 项 Gallery。分页渲染用例按消费状态选用小号场景，以检验只在小号使用的 Token。取证目录清理且 `git diff --check` 通过。

## NavMenu 八风格复测

实际 Gallery 的 `Switch the menu type` 在 1300 × 900 DIP、2× 下测试 Nova、Vega、Maia、Lyra、Mira、Luma、Sera、Rhea 的浅色与深色，共 16 组。用指针打开 inline 外层和 Item 2，点击 Option 3，悬停 Option 4，再用 Change Mode 切到 Vertical，打开一级与二级弹层。切回 inline 时两层弹出菜单收起。

| 外观 | Inline 普通面 | 悬停行 | 选中行 | 一级与二级弹层 |
| --- | --- | --- | --- | --- |
| 浅色 | `#FFFFFF` | `#F5F5F5` | `#D4D4D4` | 不透明 `#FFFFFF` |
| 深色 | `#0A0A0A` | `#262626` | `#444444` | 不透明 `#171717` |

16 组均命中实际控件。两层 inline 容器均为透明，有效底色与根菜单一致。选中文字的对比度为浅色 12.09:1、深色 7.73:1。64 张有效场景帧按坐标采样并检查视觉对照。14 组为 macOS 原生，Maia 深色和 Sera 深色因原生采集超时用同一路径的 Skia 帧验证。原生采集检错为 0／17,120／0 像素。Rhea 深色首张二级弹层仍在淡入，等待稳定复拍两张，弹层及宿主有效不透明度均为 1，关注区域差异为零。

## 暗色页面上两处辅助控件的对比度

复用原 Gallery 路由与输入驱动。Luma 深色、Nova 深色与 Luma 浅色在 2× Skia 各执行一次修复前后对照，共 18 帧，取样全部匹配。两处控件的尺寸、切换模式与收起／展开交互通过。 Luma 深色的原生静止帧也匹配轨道、滑块和按钮底色。悬停前后对照使用 Skia。

- Luma、Nova 深色，开启轨道 `#E5E5E5 → #6D6D6D`，悬停 `#B9B9B9 → #737373`。轨道与白色滑块的对比度由 1.26:1 升至 5.17:1，悬停为 4.74:1。浅色对照的轨道仍为 `#171717`。
- `Structured nav menu` 的收起按钮采用 Text 样式，默认为透明。深色悬停底色为 `#262626`，浅色为 `#F5F5F5`。收起和再次展开均通过实际点击完成。

Gallery 构建零警告、零错误。定向通过 NavMenu 与 ToggleSwitch 控件 336 项、Shadcn 主题 164 项、Gallery 13 项。

## ToggleSwitch 开、关、悬停和禁用矩阵

使用工作区实际 Gallery 的 Basic 与 Disabled 示例，由框架指针事件切换开和关，使用示例按钮将开关设为启用或禁用。检查 Nova、Vega、Maia、Lyra、Mira、Luma、Sera、Rhea 的浅、深色，共 16 组。每组采集关、关态悬停、开、开态悬停、禁用关、禁用开六个稳定帧。全部 96 张 Skia 场景帧通过，Luma 浅深色及 Nova 深色另在 macOS 原生复拍 18 张。Skia 和原生采集使用 1300 × 900 DIP、2×，校准差异分别为 0／1186／0 与 0／998／0 像素。已检查浅深色矩阵、代表性前后对照与原生帧。

| 外观 | 关轨道 | 关态悬停 | 开轨道 | 开态悬停 | 实测滑块与轨道最小对比度（启用／禁用） |
| --- | --- | --- | --- | --- | --- |
| 浅色 | `#737373` | `#6B6B6B` | `#171717` | `#454545` | 4.74:1／1.80:1 |
| 深色 | `#4C4C4C` | `#565656` | `#6D6D6D` | `#737373` | 4.74:1／4.68:1 |

修复前，浅深色关态与悬停同色。浅色启用关态滑块对比为 1.96:1，禁用关态为 1.27:1。补足关态单独的悬停轨道和浅色轨道对比后，暗色开关两种轨道比为 1.66:1，两档外观下滑块切换实际移动 19.1–22 DIP，外框尺寸稳定。禁用态保留减弱反馈并拒绝指针切换。Shadcn 定向测试 164 项通过。

## ButtonSpinner 按住时的内部竖分隔线

复现原 Gallery Luma Basic 的「疑是地上霜」。在 2× Skia 中，按住上、下箭头时，所按半边的 29 条采样行均把原分隔线 `#E5E5E5` 覆盖为按压底色 `#F5F5F5`。将竖分隔线放到按钮填充上方后，两侧按压时均为 29／29 条保留整条分隔线，圆角外框 177 个实色采样点保留。实际指针释放触发对应步进，焦点环与控件尺寸保持。已检查两向前后对照。

左置手柄也验证了临近分隔线的点击命中、按压和释放。取证校准为 0／40／0 像素。在 1.5× 下，NumericUpDown 共用部件的左分隔仍为 1 个物理像素。焦点 Token 测试使用当前输入焦点状态，沿用原有像素断言。最终 ButtonSpinner、NumericUpDown、ToggleSwitch 定向控件 85 项和渲染 166 项通过。两项验收的临时驱动、媒体和日志已清理，`git diff --check` 通过。

## ButtonSpinner 与 NumericUpDown 手柄全矩阵

8 套 Shadcn 风格 × 浅色／深色 × ButtonSpinner／NumericUpDown × 左置／右置 × 上箭头／下箭头，共 128 个 Skia 按压场景通过。Luma 浅深色、Lyra 深色另做 macOS 原生 24 个按压场景。两种控件都沿原 Gallery Basic 输入路径操作，ButtonSpinner 用原截图文本「疑是地上霜」，NumericUpDown 用 Basic usage 的共用浮动箭头。NumericUpDown 左置通过其现有内层 ButtonSpinner 的位置属性定位。

每个停稳画面逐行核对分隔线的两个物理像素及两侧底色。2× 下两半合计检查 48–72 行。浅色按压底色与分隔线相差最少 16 个 RGB 级，深色最少 22。全外框的稳定实色采样覆盖四个角和上下边，所有截面均保留描边。少量角边像素在临近截面呈现抗锯齿取样变化。左右箭头按住期间数值稳定，松开恰好步进一次。Lyra、Sera 的方角按照其主题形状检查。

NumericUpDown 左置修复前，编辑区入侵手柄 20 DIP，靠手柄一侧的编辑区指针命中失败。编辑区使用当前动画避让量重新排列后，左右均留有 6.5 DIP，编辑与两个箭头均能实际命中。Skia 和原生的分隔线区域校准分别为 0／84／0 和 0／100／0 个变化像素。前后图、八风格矩阵和原生补测图均已查看。控件 70 项、渲染 119 项及 Gallery 2 项定向测试通过。
