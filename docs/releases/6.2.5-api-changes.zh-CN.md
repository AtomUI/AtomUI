# AtomUI 6.2.5 API 变更示例

AtomUI 6.2.5 修复运行时主题切换后的 Window 后备背景。包版本变化同时会改变公开生成的注册组类型标识；升级时请重新编译已编译的消费方。

英文版本见 [AtomUI 6.2.5 API Change Examples](6.2.5-api-changes.md)。

## 快速参考

| 范围 | 6.2.4 | 升级到 6.2.5 |
| --- | --- | --- |
| 生成的注册组 | 公开的 `AtomUI.Generated.*.ControlPackageGroup_*` 类型名包含 6.2.4 程序集标识 | 带版本的程序集标识会生成不同类型名。请同步升级相关包、重新编译应用和自定义控件包，并重新发布裁剪/NativeAOT 应用；不要直接引用生成的类型名。 |
| Window 后备背景 | 运行时切换主题后，不透明内容表面可能保留旧主题背景 | 无需修改 API。内容表面现在跟随有效的 `TransparencyBackgroundFallback`，透明度切换仍由 Avalonia 管理。 |

## 1. 重新编译生成注册的消费方

`AtomUI.Controls`、`AtomUI.Desktop.Controls`、`AtomUI.Toolkits.GalleryBase`、`AtomUI.Desktop.Controls.DataGrid`、`AtomUI.Desktop.Controls.ColorPicker` 和 `AtomUI.Desktop.Controls.Extras` 的公开 `ControlPackageGroup_*` 类型名会变化。生成器将包含包版本号的程序集标识散列进组名。引用 6.2.4 组类型的预编译消费方无法绑定到相应的 6.2.5 类型。

请同步升级相关 AtomUI 包及 Generator。重新编译消费生成注册元数据的应用与自定义控件包，再重新发布裁剪或 NativeAOT 应用，使链接过程使用当前组。普通 `UseAtomUI()` 和包注册调用仍是受支持的入口；若直接引用 `AtomUI.Generated.*.ControlPackageGroup_*`，请改用这些 API，生成组名没有稳定别名。

这是生成的公开类型标识变化，不改变 TypeMap 注册机制。以 6.2.4 为基线的包 API 校验在六个受影响包的每个目标框架各报告一条 `CP0001`，共 12 条；逐包比较的 20 个包未发现其他 API 差异。这些诊断代表有意的兼容性变化，不得抑制，也不能将其描述为二进制兼容性校验通过。包布局另行校验。

## 2. 验证 Window 主题切换

有效的 `TransparencyBackgroundFallback` 变化时，包括运行时切换主题，Window 内容表面的不透明后备背景会同步更新。显式设置的 local 值继续优先；透明表面保留 Avalonia 原有行为。无需迁移 API 或主题键。使用自定义 Window 模板或显式后备背景的应用应复核主题切换效果。
