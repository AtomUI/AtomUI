## 背景

本次 Transfer 语义部件改造（`79423a09d`）涉及三处可能影响渲染的变更，需要重点确认：

1. `TransferItemDecoratorTheme.axaml`（约 49 行）：条目装饰器（hover、选中、禁用态的承载节点）视觉路径重做。
2. `TransferListItemTheme.axaml` / `TreeTransferTheme.axaml`：条目与树形穿梭的条目缩进/标记对齐。
3. `TransferListView.cs` / `TransferTreeView.cs`：条目容器的运行时创建路径调整。

Transfer 对外开放的语义部件：`root`、`source.section`、`target.section`、`actions`、`header`、`title`、
`body`、`list`、`footer`，条目级 `item` / `itemIcon` / `itemContent`，以及方向限定部件
`source.*` / `target.*`（仅作用于源列表或目标列表一侧）。

## 操作路径与判定标准

准备：运行 AtomUIGallery（`controlgallery/AtomUIGallery.Desktop`），进入
Data Entry（数据录入）→ Transfer 页面。
