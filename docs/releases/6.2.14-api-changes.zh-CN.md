# AtomUI 6.2.14 迁移指南

[English](6.2.14-api-changes.md)

本文说明从 6.2.13 升级的影响。本版本要求 Avalonia 12.1.6，并把 Skeleton、Space、Empty、Result 等控件的平台中立部分下沉到共享程序集
`AtomUI.Controls`，并调整 Empty 描述样式目标、键盘交互、焦点 Token 和文字水印默认颜色。请按下文调整用法，
并重新编译受影响的程序集。版本摘要见[更新日志](../../CHANGELOG.zh-CN.md)。

## 速查

| 范围 | 6.2.13 | 6.2.14 / 迁移 |
| --- | --- | --- |
| Avalonia 依赖 | 12.1.5 | 最低 12.1.6；升级 AtomUI 前先更新固定的 Avalonia 包 |
| `AbstractSkeleton` | `AtomUI.Desktop.Controls`，Desktop 程序集 | `AtomUI.Controls`，共享程序集；C# 补 `using AtomUI.Controls`，自定义模板改用微光块标记 |
| `SpaceItemsAlignment` | `AtomUI.Desktop.Controls` | `AtomUI.Controls`；C# 补 `using AtomUI.Controls` |
| `Card` 属性字段 | 声明在 `Card` | 声明在共享基类 `AbstractCard`；重新编译已编译的消费方 |
| `Empty.Description` | `string?` | `object?`；读取处按需转换 |
| `Result.Icon` | `PathIcon?` | `object?`；读取处按需转换 |
| Empty `description` Semantic Part | `TextBlock`，只作用于字符串描述 | `ContentPresenter`，作用于文字和自定义内容；`x:SetterTargetType` 改为 `ContentPresenter` |
| 焦点描边与 Tab 顺序 | 2 倍线宽、`FocusVisualMargin`，沿用旧停靠点 | 3 倍线宽、`FocusOutlineOffset`，更新 Token 覆盖与键盘脚本 |
| 选择器确认 | 外框接收 Tab，沿用旧 Escape 和范围确认规则 | 改为输入框接收焦点，按新的 Enter、Escape 和端点规则调整脚本 |
| 水印和主题动效 | 黑色文字水印，主题触发的过渡按配置时长播放 | 需要黑色时显式指定前景，需要较长的主题切换动效时由应用启动动画 |
| 生成的注册组 | 名称含 6.2.13 程序集身份 | 名称含 6.2.14；同步升级包并重新编译生成代码消费方 |
| 包目标框架 | `lib/net8.0`、`lib/net10.0` | 新增 `lib/net11.0`，原有框架不变，无需操作 |

## Avalonia 依赖升级到 12.1.6

AtomUI 包改为依赖 Avalonia 12.1.6（`Avalonia`、`Avalonia.Desktop` 及各平台包）。包清单把 12.1.6 声明为最低版本，
固定在 12.1.5 的解决方案须先升级到 12.1.6，才能使用 AtomUI 6.2.14：

```xml
<PackageVersion Include="Avalonia" Version="12.1.6" />
<PackageVersion Include="Avalonia.Desktop" Version="12.1.6" />
```

请把所有显式引用的 Avalonia 包更新到同一版本。Avalonia 12.1.6 是修复版本，没有移除公共 API。上游有一处应用可见的
行为变化：`Activated` 处理器执行时 `Window.IsActive` 已为 `true`，之前在事件之后才变化。AtomUI 自身无需为 12.1.6 改代码。

## Skeleton 基类移到共享层

`AbstractSkeleton` 从 `AtomUI.Desktop.Controls`（`AtomUI.Desktop.Controls.dll`）移到 `AtomUI.Controls`
（`AtomUI.Controls.dll`）。`Skeleton`、`SkeletonLine`、`SkeletonTitle`、`SkeletonParagraph` 等 Desktop 类名与公共成员不变，
改为继承共享层的新基类。

**C# 引用**：只 `using AtomUI.Desktop.Controls` 的代码需要补上新命名空间：

```csharp
using AtomUI.Controls;          // AbstractSkeleton
using AtomUI.Desktop.Controls;  // Skeleton、SkeletonLine ...

public class MySkeleton : AbstractSkeleton { }
```

AXAML 中的 `https://atomui.net` 映射照常解析，无需修改。命名空间变化后无法用类型转发保持旧二进制兼容，
继承或引用 `AbstractSkeleton` 的程序集必须重新编译。

**自定义模板**：旧模板通过模板部件 `PART_ActiveAnimationLayer` 获得动画，该部件已删除。现在微光由一组骨架中最外层的
骨架统一绘制，模板只需给要显示微光的 `Border` 标记 `IsShimmerBlock`：

```xml
<Border Name="PART_ContentLayer"
        atom:AbstractSkeleton.IsShimmerBlock="True"
        CornerRadius="{TemplateBinding CornerRadius}" />
```

未标记的旧模板不再显示微光，只显示底色。

**动画入口**：protected 的 `StartActiveAnimation()` / `StopActiveAnimation()` 签名不变，作用改为“请求重新评估是否运行微光”。
派生类不能再用它们强制启停：微光只在骨架可见、应用处于活动状态、`IsMotionEnabled`、`IsActive` 为真且 `MotionDuration`
大于 0 时运行（组合骨架另需 `IsLoading`）。新增的 `IsMotionEnabled` 默认绑定全局动效开关 `EnableMotion`。

**缓动函数**：`MotionEasingCurve` 改在渲染线程求值。自定义 `Easing` 必须是纯函数：`Ease` 不写状态、不访问 UI 线程对象，
赋值后不再修改。Avalonia 内置缓动不受影响。

**默认值**：单独使用的 `SkeletonParagraph` 中，`LastLineWidth` 默认值由 1% 改为 100%，最后一行此前几乎不可见。
依赖旧默认值的布局请显式设置该属性。

## `SpaceItemsAlignment` 换了命名空间

枚举从 `AtomUI.Desktop.Controls` 移到 `AtomUI.Controls`，成员与数值不变；`Space.ItemsAlignment` 的类型随之变化。
`Space` 现在继承共享基类 `AbstractSpace`，`ItemSpacing`、`Orientation`、`ItemsAlignment` 等成员移到基类，
按 `Space` 访问的方式不变。

```csharp
using AtomUI.Controls;          // SpaceItemsAlignment
using AtomUI.Desktop.Controls;  // Space

space.ItemsAlignment = SpaceItemsAlignment.Center;
```

AXAML 写法不变。引用旧枚举类型的已编译程序集需要重新编译。

## Card 属性字段移到 `AbstractCard`

`Card` 改为继承共享基类 `AtomUI.Controls.AbstractCard`，该基类与之前的 `Card` 一样继承 `HeaderedContentControl`。
`Extra`、`ExtraTemplate`、`Cover`、`CoverTemplate`、`IsLoading` 及其 `StyledProperty` 字段改为声明在基类。
按 `Card.CoverProperty` 或 `card.IsLoading` 书写的源码仍可编译，AXAML 写法不变。按 6.2.13 编译、通过 `Card`
引用这些字段的程序集需要重新编译。

## `Empty.Description` 与 `Result.Icon` 改为 `object?`

为支持自定义内容，两个属性及其 `StyledProperty` 放宽为 `object?`：

| 成员 | 6.2.13 | 6.2.14 |
| --- | --- | --- |
| `Empty.Description` / `DescriptionProperty` | `string?` | `object?` |
| `Result.Icon` / `IconProperty` | `PathIcon?` | `object?` |

赋值字符串或 `PathIcon` 的代码仍可编译，显示也不变。把读取结果当作原类型使用的代码需要转换：

```csharp
// 6.2.13
string? text = empty.Description;
PathIcon? icon = result.Icon;

// 6.2.14
var text = empty.Description as string;
var icon = result.Icon as PathIcon;
```

引用旧签名的已编译程序集需要重新编译。非字符串描述与字符串描述由同一个 `description` 节点呈现，样式见下一节。

## Empty `description` Semantic Part 改为内容呈现器

为对齐 Ant Design 的 `styles.description`（作用于描述外层节点，不论里面是文字还是自定义内容），`description` 部件由描述
`TextBlock` 改为同时承载文字与自定义内容的 `ContentPresenter`，`ContractType` 随之变为 `ContentPresenter`。`EmptyDescriptionStyle`
现在对自定义内容同样生效；此前对象描述没有样式入口。

```xml
<Style Selector="atom|Empty">
    <!-- 6.2.13：x:SetterTargetType="atom:TextBlock" -->
    <atom:EmptyDescriptionStyle x:SetterTargetType="ContentPresenter">
        <Setter Property="Foreground" Value="DarkSlateBlue" />
        <Setter Property="FontWeight" Value="Bold" />
    </atom:EmptyDescriptionStyle>
</Style>
```

- **无需修改**：内容呈现器复用 `TextBlock` / `TextElement` 的文本属性，按原写法设置的 `Foreground`、字体、`TextAlignment`、
  `TextWrapping`、`TextTrimming`、`LineHeight`、`LetterSpacing`、`MaxLines`、`Margin` 继续生效，并继承给描述文字。
- **需要修改**：
  - `TextBlock` 专有且不继承的属性（如 `TextDecorations`）设在该部件上不再有效，也不会报错。需要时改用自定义内容，例如
    `Description` 传入带装饰的 `TextBlock`。
  - 以 `TextBlock#Description` 为选择器，或在代码中按 `TextBlock` 查找该部件的写法，不属于公开契约，应改用 `EmptyDescriptionStyle`。

`Description` 为 `null` 时按空文本呈现，布局与之前相同。

## 生成的注册身份

生成的 `AtomUI.Generated.*.ControlPackageGroup_*` 类型名包含程序集身份，并随 6.2.14 变化。请同步升级相关 AtomUI
包和显式引用的 Generator，清理并重新编译自定义控件包与应用，再重新发布裁剪/NativeAOT 应用。不要直接引用生成的注册组
名称，也不要把 6.2.13 编译出的注册元数据与 6.2.14 包混用。做法与 [6.2.13 迁移说明](6.2.13-api-changes.zh-CN.md) 一致。

## 目标框架和 SDK

本项为新增，无需迁移。

- Release 包在 `lib/net8.0`、`lib/net10.0` 之外新增 `lib/net11.0`。面向 .NET 11 的应用改用 net11.0 资产，
  net8.0 和 net10.0 应用获得的资产与之前相同。
- 消费方的 SDK 要求不变。从源码构建 AtomUI 需要 .NET SDK 10.0.300 或更高版本，`global.json` 改为前滚到已安装的
  最新主版本 SDK。打包三个 Release 目标框架需要 SDK 11。
- net8 裁剪与 NativeAOT 后端以及 net8 包兼容桥接，改为接受已安装 SDK 选定的官方引擎，不再绑定固定 SDK 版本。
  6.2.14 之前构建、注册承载类型带静态构造函数的包，仍可用于这些后端。

包布局门禁在 `scripts/verification/package-layout-allowlist.json` 中登记了新增的 `lib/net11.0/*` 条目（#538）。

## 键盘焦点和选择器交互

- **键盘焦点描边对齐 Ant Design**：
  - 全局焦点框改为 3px、浅主色、向外偏移 1px 并跟随圆角的描边；
  - 共享 Token `LineWidthFocus` 由 `LineWidth * 2` 改为 `LineWidth * 3`。自定义视觉若引用它并需要保持 2px，改用
    `LineWidthBold`；
  - 覆盖 AdornerLayer 的 `FocusVisualMargin` 时，改用 `FocusOutlineOffset`。它表示控件边缘到描边的统一间距，单位为
    DIP，设为 0 可去掉间隙；
  - 自行设置 `AdornerLayer.DefaultFocusAdorner` 或控件 `FocusAdorner` 的应用不受影响。
- **键盘停靠点调整**：
  - Collapse / Expander 按 `TriggerType` 只保留一个停靠点；
  - ComboBox 清除按钮可用键盘到达，外框与下拉箭头不再是停靠点；
  - NumericUpDown 现在可以用 Tab 进入（此前被整体跳过）。
  - TreeView 新增一个 Tab 停靠点，用活动节点实现键盘导航。设置 `IsTabStop="False"` 可保留旧 Tab 顺序，
    `Focusable="False"` 还会禁用直接聚焦。
  - 日期 / 时间选择器的停靠点改为输入框（范围为开始、结束输入），然后是清除按钮；此前只有外框一个停靠点。
  - 依赖旧 Tab 顺序的自动化脚本需要更新。
- **日期 / 时间选择器键盘对齐 Ant Design**：
  - 输入文字即打开弹层，DatePicker / RangeDatePicker 新增按显示格式解析键入文本；
  - Enter 提交且无需确认按钮，Escape 回退（`IsNeedConfirm=false` 的 TimePicker 按 Escape 不再提交），焦点离开时按确认规则提交或丢弃；
  - 范围选择器在本次打开中两端都确认前，确认一端后转到另一端；已有完整范围的 RangeTimePicker 确认开始端后转到结束端，不再直接关闭；
  - 弹层打开时，输入框中的导航键移动日期面板焦点格或步进时间列（AtomUI 增强）。

## Watermark 和主题动效

- 文字水印默认使用宿主的 `ColorText` Token。需要固定黑色时，在文字字形上显式设置 `Foreground="Black"`，或传入指定画刷。
- 主题提交及其首帧内启动的全局时钟动画在该帧内收束。需要较长主题切换动效的应用可以在首帧渲染完成后自行启动动画。
  主题提交前已经运行的动画保持原有时序。

## 其他变更

- **日期 / 时间选择器指针交互对齐 Ant Design**（Gitee IKUUCL）：
  - 带时间的 DatePicker 点选时间格即更新候选值，「确定」提交面板显示的时间；此前单选模式提交的是点日期时的旧时间；
  - 指针离开时间格后，输入框恢复为候选值，不再显示 `日期 00:00:00`；
  - 弹层打开时，候选值使用正常文字色，只有悬停预览显示为 `ColorTextTertiary`；此前的整框灰色样式实际并未生效。
- **新增成员**：
  - `CommonLangResourceKind.Clear`，追加在枚举末尾，既有成员的数值不变；对该枚举做穷举 `switch` 的代码可能需要补分支。
    第三方语言包需要为它补充翻译，未翻译时回退英文 “Clear”。
  - `Space.IsWrap`、`Space.Justify`；
  - `Empty.Image`、`Empty.Title` 及对应模板属性；
  - `AbstractSkeleton.IsMotionEnabled`；
  - 选择器输入伪类 `:previewing`（`InfoPickerPseudoClass.Previewing`），输入框显示悬停预览时设置，自定义主题可用它为预览文字上色。

## 包验证

全部 21 个发布包已在 net8.0、net10.0 上与正式发布的 6.2.13 比较。历史 API 比较在 5 个包中报告 105 项诊断，
均已由上文各节覆盖：

- Controls（10 项）：`Empty.Description`、`Result.Icon` 签名变化，以及版本化注册组。
- Desktop.Controls（89 项）：`AbstractSkeleton`、`SpaceItemsAlignment` 移出该程序集，Skeleton、Space、Card 属性字段
  移到共享基类，Skeleton 系列类型更换基类，`Space.HandleChildrenChanged` 改为重写基类方法，移除 `FocusVisualMargin`
  Token 键，以及注册组。
- GalleryBase、DataGrid、ColorPicker（各 2 项）：版本化注册组。

其余 16 包通过，未发现引用解析诊断。不添加 suppression，本版本不声明与 6.2.13 旧二进制兼容。沿用 6.2.13 发布策略，
正式打包不传历史 API 基线，全部 21 包通过，目标框架校验覆盖 net8.0、net10.0、net11.0。应用已登记的 `lib/net11.0/*`
条目后，全部 21 包布局匹配 6.2.13；包清单声明 Avalonia 12.1.6。运行时行为变化仍由手工迁移审计覆盖，程序集 API 比较无法检测这些变化。
