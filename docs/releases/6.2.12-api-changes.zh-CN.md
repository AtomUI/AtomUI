# AtomUI 6.2.12 迁移指南

[English](6.2.12-api-changes.md)

本文说明从 6.2.11 升级的影响。Avalonia 保持 12.1.4，Release 运行时包继续提供 net8.0、net10.0，SDK 要求不变。
版本摘要见[更新日志](../../CHANGELOG.zh-CN.md)。

## 速查

| 范围 | 6.2.11 | 6.2.12 / 迁移 |
| --- | --- | --- |
| 组件弹层动效 | 各组件默认值和配置方式不一致 | 统一组件默认值，在配置 owner 上设置 `OpenMotion`/`CloseMotion` |
| 弹层关闭 | 调用方可能假定 `Close()` 立即拆除宿主 | 离场可继续播放；等待实际 `Closed`，或禁用动效 |
| ComboBox 空源 | 未启用有效筛选时不显示空态 | 默认显示空态；设置 `IsShowEmptyIndicator="False"` 隐藏 |
| DataGrid 选择 | `SelectIndicator` 下普通点击仍可能改变选择 | 指示器模式保留选择；需要单元格驱动时设置 `SelectTriggerType="Cell"` |
| 生成的注册组 | 名称含 6.2.11 程序集身份 | 名称含 6.2.12；同步升级包并重新编译生成代码消费方 |

## 组件默认动效与物理关闭

选择器和 Picker 使用 Slide；Dropdown、菜单、导航子菜单、ToolTip 与 Popover 使用各自的 Slide/Zoom 默认规格。
配置入口位于实际拥有弹层的组件：`AbstractSelect`、`InfoPickerInput`、`AbstractAutoComplete`、
`AbstractColorPicker`、ComboBox、DropdownButton、SplitButton、FlyoutHost、Flyout、ContextMenu、MenuItem
和 ToolTip。具体控件继承所属族的契约。DataGrid 筛选在实际 Flyout 配置，不新增含义不明的全表动效属性。

属性类型为可空 `AbstractMotion`。应用 Style、绑定和本地值覆盖主题默认；显式 null 禁用对应方向，清除覆盖后
恢复主题默认。直接使用的 Popup 默认仍无动效，既有显式动效定义继续受支持。

保留组件弹层无动效的示例：

```xml
<atom:ComboBox OpenMotion="{x:Null}" CloseMotion="{x:Null}" />
```

也可使用既有 `IsMotionEnabled="False"` 同时禁用组件的两个方向。禁用动效或全局 `EnableMotion` Token 时，
播放收敛到最新请求状态。

`Close()` 发起关闭；启用离场动效时物理宿主可能继续存在，直至播放结束。依赖宿主已拆除的逻辑应移到实际
Popup/ContextMenu 的 `Closed` 通知。UI 测试应推进渲染时钟，并在有界超时内等待关闭，再点击旧弹层后方内容。
不要访问内部宿主状态属性，也不要用固定 sleep 代替状态等待。

## ComboBox 空态内容

ComboBox 在空源及筛选无可见匹配时均显示空态，`IsShowEmptyIndicator` 默认 true。保留原空源显示方式：

```xml
<atom:ComboBox IsShowEmptyIndicator="False" />
```

通过 `EmptyIndicator`、`EmptyIndicatorTemplate` 和 `EmptyIndicatorPadding` 定制内容。仅设置模板时可以渲染
null 内容，但其 `IDataTemplate.Match` 必须接受该内容。默认主题提供共享内边距；内容与模板均为 null 时显示小号
内置 Empty 插画。筛选与选择语义不变。既有 `popup.empty` 与 `ComboBoxPopupEmptyStyle` 继续作为声明式定制入口，
不需要在 code-behind 查找节点。

## DataGrid 指示器选择

`SelectTriggerType` 默认仍为 `SelectIndicator`。普通单元格或选择列单元格内的空白点击现在保留选中行，只有点击
复选框/单选指示器才改变选择；current 单元格移动、焦点及编辑仍可用。需要普通单元格点击选择行的应用应使用既有
Cell 模式：

```xml
<atom:DataGrid SelectTriggerType="Cell" />
```

Cell 模式保留普通点击及 Ctrl/Shift 选择。使用指示器模式时，请移除为撤销普通单元格选择而添加的补偿事件处理。

## 生成的注册身份

生成的 `AtomUI.Generated.*.ControlPackageGroup_*` 名称包含程序集身份，随 6.2.12 发生变化。请同步升级相关
AtomUI 包与显式引用的 Generator，清理并重新编译自定义控件包及应用，再重新发布裁剪/NativeAOT 应用。
只替换 DLL 不足以更新生成代码的消费方。不要直接引用生成组名，也不要混用 6.2.11 编译的注册元数据和 6.2.12 包。
此项沿用 [6.2.11 迁移先例](6.2.11-api-changes.zh-CN.md)。

## 兼容性修复

Empty 重新挂树时恢复图片，资源暂缺时保留最后一次完整 SVG；弹层及模板退役时释放资源，动效定义不保留 owner。
Windows 无装饰置顶窗口的全屏渲染得到修复，应用配置的渲染后端不变。
DatePicker 与 TimePicker 通过共享输入主题恢复右侧附加内容模板、图标与 Form 反馈。这些修复无需增加应用配置。

## 包验证

全部 21 个发布包已与正式发布的 6.2.11 比较。历史 API 比较报告 10 项 `CP0001`：Controls、Desktop.Controls、
GalleryBase、DataGrid、ColorPicker 各一个版本化注册组，分别涉及 net8.0、net10.0。其余 16 包通过，未发现其他
API 不兼容诊断或引用解析诊断。

历史 API 门禁因此对已记录的注册身份变化失败；不添加 suppression，本版本不声明与 6.2.11 旧二进制兼容。
沿用 6.2.11 发布策略，正式打包不传历史 API 基线，全部 21 包及目标框架校验通过。全部 21 包布局匹配 6.2.11，
未修改 allowlist。上述运行时行为变化仍由手工迁移审计覆盖，程序集 API 比较无法检测这些变化。
