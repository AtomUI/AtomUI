# ShowCaseItem 放大 Overlay 视觉验收步骤

> 状态：**待视觉验收**。以下步骤供用户在真机执行并回传截图/录屏；未收到回传前，本功能不得宣称视觉验收通过。
>
> 关联设计：[2026-09-24-showcaseitem-zoom-overlay-design.md](2026-09-24-showcaseitem-zoom-overlay-design.md)
>
> 实现内容：`ShowCaseItem` 标题行新增放大按钮；点击后内容以 overlay 覆盖窗口标题栏以下全部区域；`IsZoomEnabled="False"` 可按示例退出。

## 1. 启动应用

本地调试构建并启动 Gallery 桌面应用（按 `atomui-gallery-local-debug` 技能的本地构建方式，避免与已安装版混淆）。

## 2. 操作路径（含示例入口与分类）

**入口路径**：Gallery 主窗口 → 左侧导航栏 → **Data Display（数据展示）分类 → Card 卡片 页面** → 任一 `ShowCaseItem` 示例卡片。

可检索标识：页面内示例标题如「典型卡片 / Basic card」；每张卡片标题行右侧的图标按钮组。

## 3. 预期现象

1. 每个 `ShowCaseItem` 卡片标题行右侧出现**两个** 28×28 图标按钮：左侧为放大按钮（`ExpandOutlined` 展开箭头图标，悬停提示 "Zoom"），右侧为既有的查看源码按钮（Code 图标）。
2. 点击放大按钮后：
   - overlay 以淡入 + 轻微缩放（0.96→1，约 180ms）展开；
   - **卡片贴边铺满**窗口标题栏以下全部区域（含侧边导航位置；四周无可见间距、无圆角阴影），标题栏保持可见可交互；
   - 卡片结构：顶部标题行（分割线居中带标题 + 右上角退出按钮）、大内容区、底部描述行（有内容时显示）；内边距大（上 48、左右 40、下 32 左右）；
   - 演示内容以舞台宽度重新布局，按本性二分：**铺满型内容（栅格、表格等自适应宽度的）铺满舞台宽度**；**固定尺寸内容（按钮组、单控件等）默认自然尺寸居中**。零拉伸零缩放，控件尺寸与正常渲染一致，示例自身悬停动画不受影响。
3. 退出方式（任一）：
   - 点击 overlay 右上角退出按钮；
   - 焦点在 overlay 内时按 `Escape`；
   - 退出后原卡片内容完整还原（位置、状态、输入值不丢失）。
4. 深色模式下：蒙层颜色应为深色布局底色（`ColorBgLayout` 暗色值），标题字重、留白与浅色模式一致。
5. 退出开关：设置 `IsZoomEnabled="False"` 的示例卡片标题行**不出现**放大按钮（本期内置示例未设置该属性；验证此项需临时在某页面的 `ShowCaseItem` 上加该属性后重启，或由用户指定验证页面）。

## 4. 判定标准

| 检查项 | 判定 |
|---|---|
| 覆盖范围 | 卡片贴边铺满标题栏以下全部区域（四周无可见间距）；标题栏完全可见可点击 |
| 放大形态 | 铺满型内容铺满舞台宽度（栅格条按比例铺满）；固定尺寸内容自然尺寸居中；零拉伸零缩放；分割线居中带标题 |
| 内容还原 | 放大→退出后，卡片内控件状态（输入、选中、开关等）与放大前一致 |
| 双退出通道 | 关闭按钮与 Escape 均可退出 |
| 动效 | 打开有淡入缩放；关闭立即还原（本期无退场动画，属既定 v1 简化） |
| 明暗主题 | 两种模式下蒙层/文字对比正常 |
| 退出开关 | `IsZoomEnabled="False"` 的卡片无放大按钮 |

## 5. 截图/录屏范围

- 整窗录屏一段：点击放大 → 覆盖态 → Escape 退出 → 还原态；
- 截图两张：浅色放大态、深色放大态（均含标题栏到底边的完整窗口）。
