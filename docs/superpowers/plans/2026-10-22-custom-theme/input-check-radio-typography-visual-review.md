# CT13 CR4：四个公开owner字体精确视觉审查

本包仅为CheckBox、RadioButton及各自Group接入显式有效Global FontFamily/FontSize，未配置时保持真实父级字体；四个内部只读桥与八个AXAML Setter复用既有转换器，不改Core、选择、颜色或Own公式。配置示例为Times New Roman/27，测试字体不是产品默认字体。

## 完整配方

当前Mac、Skia scale1、720×440，实际Default / Default+Dark；四owner含Group的选中、未选中和禁用项。两侧单独进程仅运行同一个Frame用例。默认原生字体→AA→1DIP→复位→父Courier New/18→AA→1DIP→复位→真实点击→Space→配置→清除→父Arial/21→父Courier New/18→焦点恢复，正常动效保持启用。

自然与直接配方使用独立实例；直接配方同时保留交错合成诊断，不能冒充独立自然。完整RGBA逐点比较，无裁剪、对齐、遮罩或容差。两次扰动的复位均0，才继续主历史。基准实际默认getter为$Default/12，前后完全相同；不把全局默认14强加到无显式配置的控件。
