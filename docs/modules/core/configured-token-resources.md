# 显式 Token 资源与继承回退

`TokenResourceExtension<TTokenKind>.WhenExplicit` 是生成式 Control Token 资源扩展的可选开关，默认false。true时，资源提供器查询同一snapshot的有效Control配置；该字段已配置才返回其值，否则返回找到的原生Unset值，阻止继续向外层资源host借值。支持已注册Control的类型化Global与Own键；普通Shared键、未注册owner/Own键仍被拒绝。Global只检查规范化共享及该Control的直接Global字段，不把算法输出猜作显式输入。普通资源查找、默认求值、缓存及优先级不变。

别名按既有canonical映射检查存在性；读取值仍走原资源投影。类型化owner键同时验证identity与真实Own归属。查询只针对实际请求的Control，不遍历所有控件或创建新的配置来源标记。

## 资源缺省不等于Setter缺省

Avalonia12的绑定表达式即使结果Unset，也会用目标属性的metadata默认值填充样式入口。因此不能把可选资源直接绑定到可继承属性，再声称其缺省保持原生继承。使用ControlTheme MultiBinding提供明确回退；数字与enum等类型转换也须明确声明。

Button的FontWeight是既有double Own，资源默认400；未配置时保留实际继承字体，显式400仍可覆盖Bold祖先。ControlTheme选择继承值或显式字重，再由原生样式优先级处理实例/应用Style。第三路保留普通资源查找，让局部资源字典覆盖继续生效。有限数值转换不创建新的优先级规则。

实际InheritanceParent是Avalonia受保护成员，可能与逻辑/视觉父节点不同；Button只在挂载期观察该原生父对象的FontWeight并投射内部只读值，分离释放订阅。最终FontWeight Setter仍在AXAML，编译绑定使用注册的AvaloniaProperty accessor，无反射路径。

该开关表示有效主题配置中存在对应Global/Own输入，不以数值等于默认值猜测缺省，也不自动把任意手工资源赋值认定为ThemeConfig覆盖。用于可继承属性时，控件文档必须说明缺省回退及实际投射；不能批量给所有Token添加此开关。

## FontFamily 的继承兼容消费

Button/Dropdown、Hyper、Split、Option/Group的最终FontFamily由ControlTheme MultiBinding选择：真实继承字体、WhenExplicit存在位、普通类型化资源值。无直接配置时保留祖先字体，明确配置同值也视为存在；清除后恢复当前祖先。普通资源值在存在位有效时继续遵循原生资源查找。局部资源覆盖应使用生成的强类型identity构造与模板相同的key，例如`ControlTokenResourceKey.Global(ButtonTokens.Identity, SharedTokenKind.FontFamily)`，不要用丢失owner-type资格的字符串identity替代字典key。

Core内部ControlTypographyBindings通过编译Self observable观察实际父字体，目标控件仅用内部接口暴露受保护InheritanceParent；不猜逻辑父、不反射、不直接给目标FontFamily赋值。ParentProperty与逻辑挂载刷新，逻辑分离停止父订阅，原生绑定释放时移除事件和订阅，避免长寿命父字体源保留已移除控件。原有Button FontWeight实现保持。

WhenExplicit是输入存在性合同，单独Unset仍不能保证Setter继承。该机制不应批量加到所有字段；每个控件须明确字体回退、资源覆盖及native Style/local优先级并独立验证。

## 输入控件的有限字体选择

LineEdit三档字号使用12输入向量：继承值、SizeType、IsCustomFontSize与中/小/大三组Own存在位、Global存在位、最终Own资源。SearchEdit/NumericUpDown使用9输入向量，三组分别为Global存在位与最终Global资源；没有自定义字号标志的ButtonSpinner使用8输入形态。NumericUpDown声明PresetFallback，保留原实际文本的中档默认，IsCustomFontSize=true仍返回真实继承。其他预设字号使用4输入的有限SizeType选择。均不以字段数值猜激活，不伪造Own；Custom取原中档默认。最终字号由ControlTheme根Setter选择，普通应用Style及LocalValue保留优先级。

TextBox、TextArea、SearchEdit字体族同样采用可选Global与真实继承回退。asset-only EmbeddedTextBox通过自身主题恢复组合父继承，避免复用公开TextBoxTheme时跨identity获取公开TextBox字体配置。这个排版继承使用真实InheritanceParent，与内部资源owner通过逻辑/模板路径解析的职责不同。

## 无字号预设的排版消费

Timeline／TimelineItem 没有 SizeType 字号预设，其 FontSize 使用三输入：真实继承值、Global 存在位、最终 Global 值。未明确配置时保留当前祖先字号；明确配置后取有效值，清除回到当前继承，不增加 IsCustomFontSize API。原有 8／9／12 输入的预设路径不变。

Foreground 同样使用真实继承前景、ColorText 存在位、最终画刷三输入；Core 复用有限类型的继承订阅，不反射、不将 Unset 当作继承保证。控件只通过内部只读接口暴露受保护父对象，最终属性由 ControlTheme Setter 声明；本地值及应用专用 Semantic Part Style 遵循原生优先级。这个兼容选择不自动改变未配置时的默认文字色，不能用来宣称旧暗色可读性已修复。

## 历史借用角色的显式 owner 迁移

TimeViewCell原颜色取ListView角色，既有ListView Own及control Global定制仍需保留。仅用普通WhenExplicit不足以区分Cell直接输入与根Global输入：根Global存在时，直接切换为Cell值会跳过旧ListView明确配置。内部OwnerTokenResource的WhenControlExplicit因此只检查解析到的注册owner的直接Global输入，缺省返回原生Unset；最终有效值仍走同一snapshot资源查询。这个内部存在位由ExplicitTokenResourceKey的默认false标志区分，普通公开WhenExplicit及既有调用保持原合同，不增加public API或资源ID。

颜色选择按“旧角色有效画刷、Cell直接存在位、Cell有效画刷”三输入在AXAML完成；根Global对旧角色的影响继续由旧角色默认求值承担。字体仍使用普通WhenExplicit与真实继承回退，因为字体没有旧ListView Own覆盖入口。算法输出不被猜作字段明确输入。

缺省Setter还包含样式优先级：即使回退值数值相同，一个新增的disabled条件Setter仍可能遮住原应用Style。Cell通过内部bool与有限IBrush存在性转换在AXAML门控disabled Style；未配置时整个Setter不激活。配置后Foreground在owner上声明，经原模板绑定到文字，LocalValue及生成专用Semantic Style保留原生优先级，清除则移除这条条件Setter。不以代码查找Part赋值。

## 动效的兼容默认

内部TokenTransitions在实际Control的style Setter创建每owner独立原生集合，按声明kind更新Duration，保留Property/Delay/Easing和集合身份。没有时长输入的prototype仍是静态内容。没有反射激活，也不在每帧重建集合。

确需保留原先无动画默认的资产可以声明UnconfiguredDuration：仅在已注册实际owner的规范配置直接提供对应Global字段时使用资源值，否则使用声明回退。不注册身份的primitive保持该回退；内部owner绑定复用WhenExplicit查询并阻止Shared键误入该协议。IndicatorScrollBarThumb使用0，以保留其旧实际时长；明确MotionDurationMid配置后生效，清除恢复0。局部资源字典本身不被猜成主题配置存在位。该形态不是通用迁移开关，普通动效集合仍直接消费有效Global。
