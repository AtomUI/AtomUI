# Shadcn FloatButton 描边验收

## 范围

- 重放实际 Gallery 的 Basic 和 Type，确认 Default 的白底轮廓、实际滚动位置、悬停、按压和真实 Tab。
- 复用普通 Button 的 Shadcn 主题配色。FloatButton、BackTop 和按钮组从现有 Token 与 ControlTheme 绘制，覆盖八种风格的浅深色与 Compact，并核对 Ant Design。

## 根因与实现

实际 Nova 浅色示例的按钮面与外界均为 `#FFFFFF`，边界厚度为 0。原生 Retina 截图的 Default 轮廓 24 个采样点均未达到 10 级色差，原阴影的紧邻背景只暗 1–3 级。Basic 尺寸为 36 × 36 DIP，离垂直滚动条 8 DIP。原始 Viewport 为 427.5 × 300 DIP，Extent 为 427.5 × 500 DIP，滚动偏移 0 到 80 DIP 时按钮位置一致。

专属主题算法复用对应风格的描边配色，并按源色的 alpha 合成浮动表面。按钮轮廓使用已有边框属性单独绘制。方形组的外框位于既有内容框内，沿用现有分隔线与布局。Vega 的 `shadow-xs` 是描边默认值，显式阴影和独立的本地 `BoxShadow` 仍走现有优先级。 [官方 Button](https://ui.shadcn.com/docs/components/base/button)

## 定向验证

改动前的四个 Nova 模式均因实际 `Frame.BorderThickness` 等于 0 而失败。首版复验测到暗色合成底板为白色，16 个暗色用例均复现。首版独立方钮的说明文字也因边框参与测量而多出 2 DIP。修正颜色合成和边框绘制层后通过 35 项临时断言，包括全部 32 个 Shadcn 配方、同实例方钮尺寸、暗色真实指针悬停与按压、方形组唯一外框、BackTop、显式 Vega 阴影等值覆盖与移除，以及切换到 Ant Design Dark。

原有 Token 生效测试的两条边框数据行切到实际消费它们的 Shadcn 外观。首次宽筛同时命中了已有 `InputFamilyEffectTests.Owner_Read_Lists_Match_The_Primitive_Themes` 清单差异，涉及 InputControlFrame 的 `ColorTextDescription` 与 `ColorTextQuaternary`。FloatButton 的定向筛选只覆盖本次涉及的控件。

## macOS 原生复拍

- 在实际 Gallery 的 1300 × 900 DIP 窗口以 Retina 2× 捕获。最终校准的同状态、1 DIP 扰动、复位差分为 0／1304／0 像素。
- Nova 浅色 Basic 与 Type 的 Default 四向采样均读到 1 DIP 的 `#E5E5E5` 描边，与白底相差 26 级。圆周达到 10 级色差的采样从 0／24 升到 22／24。Vega 浅色的四向边界相同，保留 `0 1 2 #0D000000` 阴影。
- 同实例切到 Nova 深色，背景为 `#0A0A0A`，按钮面为 `#212121`，合成后的四向描边为 `#424242`，圆周 24／24 达标。切回浅色恢复原描边。暗色原图标与底色最大差值由首版的 5 提升到 217。
- Basic 的尺寸为 36 × 36 DIP，距可见滚动条 8 DIP。内层滚动 0 到 80 DIP 后原位置一致。真实 Tab 进入按钮，焦点区域变化 1760 像素。左、中、右均命中按钮内节点。原生输入路由测得浅色悬停 `#F5F5F5`、按压 `#E9E9E9`，释放后清除按压状态。

临时窗口隔离外部物理鼠标事件，测量的交互由实际 Avalonia 输入路由驱动。原生临时工程、截图和测试探针已清理。最终定向验证通过 Shadcn 164 项、渲染 54 项、FloatButton 控件 56 项、Gallery 3 项。Gallery 构建通过，五个 C# 文件的成员布局审查及 `git diff --check` 通过。

## 带说明按钮的排版与垂直对齐

Luma 原生 Gallery 的两个图标加文本按钮均为 40 × 58.5 DIP，图标在文字上方，三个按钮都将 `HELP INFO` 拆成两行。Shape 示例中的 Circle 和 Square 在左上角 8 × 8 DIP 区域均有 28 个填充像素，外形没有可见区别。四个 Luma 配方的实际模板断言均复现纵向排版。

独立方形描述布局按可用尺寸测量。图标停靠在文字前方，文字得到有限的剩余宽度并支持两行；默认样式保留完整原文作为按钮的可访问名称，自定义模板通过原内容部件呈现。浅深色及 Compact 共享对应风格的尺寸令牌和上轮描边，纯图标方钮使用较小圆角。窄宽度仍保留一部分文字空间，应用提供的说明行高可覆盖默认字面，组内描述继续使用原有行高。

原先三枚按钮按底边定位。当 Luma 图标加文字按钮为 44 DIP、中间纯文字为 40 DIP 时，中间中心低 2 DIP。Gallery 无头回归将两侧按钮都加高 4 DIP，同样测到中心差 2 DIP。示例改为根据同一视口定位中心，右侧锚点按内容视口避开滚动条，窄窗使用同列的多行布局。

- macOS 2× 的中心定位复拍中，Luma 的三枚按钮中心均为 401 DIP，Sera 均为 399 DIP，Mira 均为 405 DIP。中间文本中心与对应按钮中心差均为 0 DIP。
- Luma 的方形与圆形左上角填充像素分别为 110 与 28。1100 DIP 窄窗的三枚按钮纵向间距均为 18 DIP，横向中心差最多 0.25 DIP。原内层 300 DIP 视口和 500 DIP 内容高度保留，滚动 80 DIP 后按钮坐标一致，原生滚动条滑块移动 46.72 DIP。
- 原生 Luma 的真实 Tab 到达 FloatButton，左中右都命中实际按钮，焦点区域变化 3228 个物理像素。采样校准的同状态、1 DIP 扰动、复位为 0／2779／0。

## 收紧浮动占用

根据进一步反馈，将说明按钮的左右留白改用各风格小号按钮的取值，上限 10 DIP，上下各 2 DIP。最小高度使用各风格常规按钮尺寸，纯图标仍用各风格图标大号尺寸。默认宽度上限为最小宽度的 2.5 倍。三个展示按钮收拢到视口右侧，窄窗按两行内容的行高预留空间。

原生 Sera 中，三枚说明按钮从 101／116／101 × 44 DIP 收紧到 75／92／75 × 40 DIP。整排占用从 375.5 DIP 降至 291 DIP，左侧释放 90 DIP 与底层内容重叠的区域。三枚按钮和中间文字中心 Y 均为 405 DIP。两侧显示全量两行文字，中间完整显示一行。纯图标 Circle、Square 的点击区域为 44 × 44 DIP。

Sera 在 1100 DIP 窗口下使用三枚 40 DIP 高的纵排按钮，间隙为 8／8 DIP，总高 136 DIP。原 300 DIP 视口、500 DIP 内容和 80 DIP 滚动定位均通过。可见滚动条滑块移动 46.72 DIP，宽窗距滚动条 12.5 DIP。同状态、1 DIP 扰动、复位差分为 0／2017／0。

紧凑占用探针先复现 Sera 四个配方的过宽左右留白以及 44 DIP 说明高度，再在同一控件结构上验证八种风格各四种配方。最终 32 项占用探针全部通过。清理临时用例、原生驱动和媒体后，主题 164 项、渲染 60 项、控件 56 项、Gallery 3 项定向测试通过。Gallery 构建与工作区差异检查通过。
