# Motion 播放与生命周期

本文拥有[Motion 系统](overview.md)的请求、完成、取消、终态持有与属性所有权。控件接入见
[目标与布局](targets-and-layout.md)，测量门槛见[性能验收](performance.md)。

## 请求模型

一次播放依次执行准备、取得请求所有权、提交、播放、稳定态提交和释放。
准备建立不可变参数/几何快照并验证轨迹，成功前不替代目标上的已有请求，也不写入目标。

一个目标同时只有一个显式 Motion 请求。新请求准备成功后整体替代旧请求，不实行部分通道取消。
需要同目标并行时使用 ParallelMotion；无冲突的主题状态属性可以继续独立工作，但相同属性不能存在两个有效写入者。

同一目标状态的重复可见性请求幂等，不反复重播；一次性 PlayAsync 调用则表示明确的新播放意图。
控件业务状态只由业务 owner 保存，运行层保存请求身份与呈现目标，不维护第二套展开项或选中项集合。

## 结果

| MotionOutcome | 合同 |
| --- | --- |
| Completed | 当前请求到达目标；未播放的短路路径 WasAnimated=false |
| Superseded | 被新请求整体替代，旧业务完成动作不得执行 |
| Cancelled | 外部取消，撤销当前覆盖并恢复最新底层基线，不默认停在中间帧 |
| Detached | 目标或 owner 生命周期失效，释放，不接触新模板/宿主 |
| NotReady | 未挂载或尚无有效布局，未启动且不取得目标请求所有权 |

MotionResult 携带请求标识和是否实际播放。真实执行/配置错误通过异常传播，预期取消与替代不伪装成故障。
调用 PlayAsync 与定义配置位于目标 UI 线程；外部取消可以跨线程发信号，实际视觉修改与释放仍回到目标线程。
fire-and-forget 接入口必须观测故障，不通过 catch-and-ignore 隐藏执行异常。

底层 PlayAsync 不等待有效布局，未就绪立即返回 NotReady。有效布局可以包含合法零尺寸，不能只检查宽高是否大于零。
已挂载控件的接入层可以在一次布局完成后重新核对，仍不可用则按业务目标走无动画稳定流程。
缺少必要通道/布局能力是明确配置异常，与暂时未就绪分开，不无限等待或用固定延时假装就绪。

## 完成与异常

只等待实际启动的有限通道。未变化通道跳过，不创建完成通知或无意义的等待。
正常完成来自执行器的可靠结果；`Ease(t)≈1` 不是时间终点，也不能区分超调或自定义曲线。
watchdog 仅处理异常停滞，依据实际启动时刻、Delay 与时长设置；触发后返回故障/超时，不作为正常成功。

目标就绪时，零时长或禁用动效直接按目标与 FillMode 提交稳定态，不建立播放实例、帧订阅或周期 timer。
目标本身未就绪仍服从 NotReady，控件 owner 可直接提交其完整稳定状态，不要求为了关闭宿主先启动 Motion。
运行错误与清理错误分别保留；清理某个句柄失败不能跳过其他资源释放。

## 终态与 FillMode

| 模式 | Delay 期间 | 正常结束 |
| --- | --- | --- |
| None | 底层状态 | 撤销覆盖，恢复最新基线 |
| Forward | 底层状态 | 持有终点 |
| Backward | 持有起点 | 撤销覆盖，恢复最新基线 |
| Both | 持有起点 | 持有终点 |

内置有限入/离场默认 Both，避免结束到 owner 隐藏之间出现基线闪回。外部取消一律恢复基线，不提交 Forward 终点；
替代采用下一节的连续交接，不执行外部取消的基线恢复路径。

Forward/Both 的终点转交目标侧终态记录，只保留呈现值和可撤销覆盖，不保留 AbstractMotion 定义、CTS、任务、帧订阅或 watchdog。
下一次准备成功的请求、Motion.Reset(target)、目标 detach、模板/owner 失效都必须释放终态覆盖。
Reset 只允许无活动播放时调用；活动播放中明确报错，调用者先取消并等待结束。
恢复模式的离场不提供异步隐藏窗口；需要结束后再关闭宿主的 owner 使用 Both/Forward。

底层绑定在持有期间可以更新，释放恢复最新值。活动运行与有意持有的终态是两个资源统计项：播放结束前者归零，
Reset/detach 后终态覆盖也必须归零。终态记录不得反向保留业务 owner 或定义对象。

## 替代与反向

新请求在取消旧执行之前捕获可用呈现值，先发布新身份，再完成句柄交接并使旧请求整体 Superseded。
旧 finally 只能释放仍归自己所有的资源，不能修改新请求的值、origin、终态或可见状态。
底层能力必须支持这一交接，不能把合成端客户端基值当作当前呈现值。

新旧共有通道要求呈现值连续；旧独有通道恢复最新基线。跨家族未声明通道不保证连续，需要时显式声明其终态或组合。
速度导数连续不属于默认保证。未中断轨迹的规格校准与中断行为分别验收，不为“平滑”静默改为弹簧。
下一请求不继承上一请求未声明的终态覆盖，避免后续清理时重新暴露旧位移或缩放。

## 属性所有权

临时属性覆盖必须可撤销，不能保存旧数值后 SetValue 写回。绑定和主题在覆盖期间继续存在并能更新。
应用 RenderTransform 进入合成 TransformMatrix，Motion delta 位于独立合成通道并在其后组合（缩放、旋转围绕 CenterPoint，最后平移）；二者互不覆盖，不需要模板变换边界。
相同属性上的主题 Transition 与显式 Motion 通过接入边界协调，不通过全局禁用过渡处理其他 owner 的属性。

## owner 与释放

运行与目标/owner 生命周期关联，不使用进程级强引用目标字典。模板替换先使旧登记失效，再释放旧资源。
detach、容器回收、owner 销毁均取消旧请求；重新接入根据最新业务状态初始化。
可通知的属性写入与用户回调可能重入，每个后续提交都核对当前请求，不假设一次方法内不会出现新意图。

| 获取项 | 释放边界 |
| --- | --- |
| CTS、任务完成协调、watchdog | 本次请求结束的统一释放入口 |
| 帧/结束事件、目标生命周期订阅 | 请求结束或目标失效 |
| 播放中的属性与动画句柄 | 当前请求结束、替代交接或失效 |
| Forward/Both 终态覆盖 | 后继成功请求、Reset 或目标/owner 失效 |
| 布局接管与缓存 | 请求结束/取消、模板或布局 owner 失效 |

弱引用不能替代释放。关闭/移除/销毁前，业务 owner 必须重新核对请求标识、目标/模板身份和最新业务意图，
不能仅因某个 await 返回 Completed 就关闭当前新宿主。
