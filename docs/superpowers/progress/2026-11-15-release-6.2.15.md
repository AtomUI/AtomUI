# AtomUI 6.2.15 发布准备

发布范围暂按维护线的下一个版本 6.2.15 准备。基线是已发布的 `v6.2.14`（`f11459de0`），源码快照是 `13600a390`，共 34 个提交。

## 破坏性变更审计

源码范围内没有 `!:` 标记。以下结论依据实际差异，并参照 6.2.14 迁移指南对字段所有者、焦点顺序和生成注册的处理。

| 候选项 | 是否破坏性 | 证据与迁移动作 |
| --- | --- | --- |
| Form（`e70ab1642`） | 是 | `IForm` 增加接收 `FormValidateOptions` 的必实现重载。自定义实现须补齐该方法。自动化和自定义验证反馈也要核对校验器本地化默认提示。 |
| Rate（`36cfb96d5`） | 是 | `ToolTips` 和 `ToolTipsProperty` 离开共享 `AbstractRate`，由 Desktop `Rate` 声明。共享基类引用、派生控件和旧二进制需要迁移。 |
| 输入、Slider、Steps、Collapse、Carousel、Button、Tab（`1dd46690f`、`b809aef50`、`dc4a30bbc`、`759a225ba`、`550f12141`、`27676d074`、`e4e0607bb`） | 需要迁移自定义子类、模板及反射调用 | 既有 Desktop 类保留公共属性和字段别名，包括 Form 与 Tab 的部分 `DirectProperty` 所有者。共享输入层新增与 Desktop 同名的 `AbstractTextInput`，同时导入两个命名空间时须限定名称。输入附件模板和 Button 的图标/加载分支改变树结构，对依赖精确旧路径的外部模板选择器有影响。检查重新分配的共享属性所用的 owner、注册和通知行为。 |

| ListBox、ListView、Transfer（`84024c1fe`、`f455f659e`） | 是，焦点顺序 | 键盘焦点按项落位，ListView 组标题和 Transfer 行内复选框跳过 Tab，焦点描边移至条目内侧。自定义主题和键盘自动化须跟随条目焦点。 |

## 首轮回归与修正

- 三个聚焦筛选合计 1081 项通过。首轮 `scripts/run-full-regression.sh` 执行 14 个测试项目，共 7073 项，耗时 07:28，失败两项。
- `NavMenuEntryPopulationScalingTests.Appending_Node_Entries_One_At_A_Time_Scales_Near_Linearly` 的墙钟耗时比例在全量中为 33.30，超过 24，聚焦测试已通过。同一追加路径按输入量 500 和 4000 测量当前线程的托管分配量，以捕获全量扫描重新分配整个 ownership 快照的二次开销。
- `ToggleSwitchShowCasePageTests.ToggleSwitch_Semantic_Style_Example_Applies_The_Official_Style_Values` 读取的新布局槽为 `0, 0, 20, 20`。原图形位置已由渲染平移承担，改为转换到所属开关坐标后核对原 `15, -3, 20, 20` 矩形，保留颜色、阴影、样式和尺寸断言。
- 单变量复核临时使单项追加直接走全量校验。根追加和子项追加的分配倍率分别为 58.82 和 59.34，均超过 24，两项断言失败。移除临时改动后，NavMenu 和 ToggleSwitch 控件聚焦 15 项通过，Gallery ToggleSwitch 4 项通过。保留现有测试的位置与数量，运行时源码差异为空。
- 第二轮全量共 7073 项，耗时 07:43。NavMenu、ToggleSwitch 均通过。唯一失败为 `ComboBoxShowCasePageTests.ComboBox_ShowCase_Filter_And_Empty_Content_Examples_Render`，模板空态预期内边距 24，窗口全局查找返回 16。连续切换时关闭动画保留前一个 `PopupFrame`。断言改从当前 ComboBox 所属 Popup 的 Child 读取，并验证该 frame 实际连接到当前窗口。原有业务操作、动画、样式和尺寸断言保留。
- 同序列单变量复核将前一空态的关闭动画延长至 5 秒。全窗口查找拿到上一弹层且内边距为 16，当前 Popup 的 frame 内边距为 24，测试通过。移除探针后用原时长跑 Gallery ComboBox 与 ToggleSwitch 现有用例，9 项通过。
- 最终 `scripts/run-full-regression.sh` 输出 `[SUMMARY] TOTAL: 7073 个测试全部通过, 总耗时 07:08`。默认 14 个项目，`AtomUI.Localization.IntegrationTests` 属默认排除项。三个测试修正均保留原用例数量，临时验证改动已移除。
