# Avalonia 12.1.5 Upgrade Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan task-by-task after user approval. Do not create branches, worktrees, commits, or delegate implementation without separate authorization.

**Goal:** 将 Avalonia 12.1.4 升级为 12.1.5，删除已有等价上游实现的 Dispatcher 时钟补丁，维持其余 AtomUI 行为。

**Architecture:** 继续使用官方 NuGet 包与中央版本。只移除已被框架时钟偏移转换覆盖的反射适配；Wayland 帧节奏/初始缩放保留原算法，按后续 A6 删除版本白名单，改用完整成员契约与状态守卫。其他 hook 的保留依据不在本计划复制。

**Tech Stack:** Avalonia 12.1.5、NWayland 0.11.0、.NET 8/.NET 10、现有 Avalonia Headless/xUnit 与 Gallery NativeAOT 入口。

**Spec:** [源码评估、平台变化与 hook 去留](../specs/2026-11-05-avalonia-12.1.5-upgrade-design.md)。

## Global Constraints

- 状态：2026-11-05 升级与 A4/A5/A6 工程范围已验证；用户按 A7 授权全部改动提交与推送当前升级分支。Linux/Windows 留用户复验，证据统一见 Spec。
- 在当前目录的 `feature/upgrade-12.1.5` 工作；分支自 `release/6.0` 创建，用户已针对具体方案回复「我同意」。不创建 worktree；提交与推送按后续 A7 授权。
- 保留既有 `docs/superpowers/plans/2026-11-04-release-6.2.12.md` 用户改动；不重写历史发布记录。
- Avalonia 统一为 12.1.5；NWayland 保持 0.11.0；不升级其他依赖家族。
- 不改公共 API、Popup/滚动/阴影/布局/动效契约；macOS 最低 12.0 的上游变化必须明确披露。
- 新测试临时优先，验证后删除；默认净新增常驻测试为 0，清理后仍需模块验证。
- 不主动执行 change/full regression；按 A3 本轮只执行 macOS，Linux/Windows 原生复验交用户在对应电脑执行；不以 macOS/headless 代替平台证据。
- 发现超出此清单的新不兼容时更新计划并交用户评审，不顺手扩展功能。
- 后续用户明确授权修复 DataGrid IL2026/IL3050 和 SDK NU1903；选择保留 SDK、修正发布依赖到安全版本。新增 Task 6/7，依据与批准统一记录于 Spec 的 A4/A5。

## Review Focus

1. Wayland 按实际成员契约接入，不因版本/commit 文本变化失去原有帧节奏与首帧缩放。
2. 初始化前已有 timer 必须保持截止值，后启动 timer 不增加后端起点差；删除 hook 不撤销 Startup Prepare 时机约束。
3. 带阴影/嵌套 Popup 的坐标与输入形状必须一致；RequestedPlacement 的 Custom 路径不能与框架 Pointer 路径混淆。
4. 继承框架的 Button/ComboBox/TreeView/TextBox 行为与数据绑定要实测，编译不能替代行为证据。
5. macOS 12.0 下限、net8/net10 包消费和 AOT 私有成员保留必须反映真实最终产物。
