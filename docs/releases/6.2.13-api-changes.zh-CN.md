# AtomUI 6.2.13 迁移指南

[English](6.2.13-api-changes.md)

本文说明从 6.2.12 升级的影响。Avalonia 升级到 12.1.5，Release 运行时包继续提供 net8.0、net10.0，SDK 要求不变。
版本摘要见[更新日志](../../CHANGELOG.zh-CN.md)。

## 速查

| 范围 | 6.2.12 | 6.2.13 / 迁移 |
| --- | --- | --- |
| Avalonia 依赖 | 12.1.4 | 最低 12.1.5；升级 AtomUI 前先更新固定版本的 Avalonia 包 |
| 生成的注册组 | 名称含 6.2.12 程序集身份 | 名称含 6.2.13；同步升级包并重新编译生成代码消费方 |

## Avalonia 依赖升级到 12.1.5

AtomUI 包现在依赖 Avalonia 12.1.5（`Avalonia`、`Avalonia.Desktop` 及各平台包）。包清单声明的最低版本为 12.1.5，
固定在 12.1.4 的解决方案须先升级到 12.1.5 才能使用 AtomUI 6.2.13：

```xml
<PackageVersion Include="Avalonia" Version="12.1.5" />
<PackageVersion Include="Avalonia.Desktop" Version="12.1.5" />
```

所有显式引用的 Avalonia 包都应升级到同一版本。AtomUI 6.2.13 依赖 12.1.5 中的上游修复：已移除 Wayland 共享时钟
兼容路径，以及用于刷新选区前景色的内部输入文本 presenter。输入模板仍保留 `PART_TextPresenter` 与 `input`
Semantic Part，节点改为标准 Avalonia `TextPresenter`。应用全局的 `TextPresenter` 类型选择器现在也会命中这些输入节点；
若无意作用于 AtomUI 输入，请收窄选择器范围。

## 生成的注册身份

生成的 `AtomUI.Generated.*.ControlPackageGroup_*` 类型名包含程序集身份，并随 6.2.13 变化。请同步升级相关 AtomUI
包和显式引用的 Generator，清理并重新编译自定义控件包与应用，再重新发布裁剪/NativeAOT 应用。只替换 DLL 而不重新
编译生成代码消费方是不够的。不要直接引用生成的注册组名称，也不要把 6.2.12 编译出的注册元数据与 6.2.13 包混用。
做法与 [6.2.12 迁移说明](6.2.12-api-changes.zh-CN.md) 一致。

## 兼容变更

- DataGrid 在 `DataGridSelectTriggerType` 末尾新增 `Row`。默认值仍为 `SelectIndicator`，`Cell` 语义不变。
  对该枚举做穷举 `switch` 的代码可能需要补充 `Row` 分支。
- `ListView` 新增 protected 辅助方法 `EnumerateSourceIndexes()`，供派生类的选择逻辑使用。
- GalleryBase 新增 `GalleryShellOptions.CollapsedSidebarHeaderSpacing`（`double?`，默认 `null`）。侧边栏折叠后，
  Header Action 下方保留跟随 `UniformlyMarginXXS`（默认 4）的间距。为绕过原问题而自行给 Header Action 加边距的
  产品应删除该边距，否则间距会叠加。负数、NaN 与无穷值会抛出 `GalleryConfigurationException`。
- Masonry 重新布局时不再对既有项做动画；新项仍淡入，移除项仍淡出。API 不变，`MotionDuration` 现只作用于入场淡入。

以上变更无需应用迁移。

## 包验证

全部 21 个发布包已与正式发布的 6.2.12 比较。历史 API 比较报告 10 项 `CP0001`：Controls、Desktop.Controls、
GalleryBase、DataGrid、ColorPicker 各一个版本化注册组，分别涉及 net8.0、net10.0。其余 16 包通过，未发现其他
API 不兼容诊断或引用解析诊断。

历史 API 门禁因此对已记录的注册身份变化失败；不添加 suppression，本版本不声明与 6.2.12 旧二进制兼容。
沿用 6.2.12 发布策略，正式打包不传历史 API 基线，全部 21 包及目标框架校验通过。全部 21 包布局匹配 6.2.12，
未修改 allowlist；包清单声明 Avalonia 12.1.5。上述运行时行为变化仍由手工迁移审计覆盖，程序集 API 比较无法检测这些变化。
