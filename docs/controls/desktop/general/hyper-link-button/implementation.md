# HyperLinkButton 实现

Common/AbstractHyperLinkButton拥有公开链接动作、visited/loading/icon-only/danger伪类、尺寸和图标契约；Desktop/Buttons/HyperLinkButton应用模板，HyperLinkButtonTheme提供状态与布局，HyperLinkButtonToken拥有独立Own默认。导航成功的异步结果只更新IsVisited，不重建主题或内容。

IsLoading由Common基类同步到`:loading`，模板负责显示loading图标、隐藏用户图标、配置Spin及读取本控件有效Global OpacityLoading。清除状态后回到原有图标与透明度规则；主题更新、模板替换和分离重挂均读取当前状态，不通过禁用控件模拟loading，不改变Avalonia Button的Click/命令或导航语义。

Icon非空且Content为null时激活`:icononly`，Icon/Content变化实时切换；模板据此选择既有OnlyIconSize、IconOnyPadding和零图标margin，loading替代节点沿用同一指标。IsDanger同步到`:danger`，ControlTheme拥有普通/hover/pressed危险颜色，disabled规则保持优先。状态同步不写入Padding、尺寸或Foreground本地值。

默认模板组合loading图标、IconPresenter和内容呈现器。三档与Custom的属性投射、disabled/loading等选择器均由ControlTheme负责；模板替换必须保留所依赖的命名部件和行为。加载margin绑定跟随实际图标margin，不能把私有部件名称升级为公开Semantic Part。ControlTheme style Setter中的编译ElementName无法解析模板内命名部件，实际编译器报AVLN2000；反射命名绑定不作为AOT回退。因此保留有明确原因注释的同模板代码绑定，使用Template优先级，重模板时释放并替换。两个端点均属于当前模板，不持有外部资源host；AXAML负责图标margin，loading不再重复设置同一资源而压制实际源值，原生应用Style trigger/本地属性可覆盖。

Own默认函数按字体→DIP布局行高→内边距的图执行；explicit存在位使下游默认读取已覆盖上游，显式Padding不被重算。源码位置为`src/AtomUI.Desktop.Controls/Buttons/HyperLinkButtonToken.cs`，基类为`src/AtomUI.Controls/Buttons/AbstractHyperLinkButton.cs`。修改字段须同步[Token合同](token.md)，完整模板和订阅修改须验证替换、分离与释放。

Global尺寸、图标、motion与状态色由HyperLinkButton自己的类型化资源解析；两项Transition时长动态读取自身MotionDurationMid，不在主题载入时固化。

loading图标的Spin由当前IsMotionEnabled开关约束；关闭时图标仍可见并保留loading透明度，恢复时重启旋转。该规则声明于ControlTheme，不创建额外动画或订阅。

Frame的BorderBrush/BorderThickness使用TemplateBinding；Background使用编译TemplatedParent绑定，明确Template优先级及TargetNullValue=Transparent。该回退只作用于Frame，root默认getter和未设置状态保持null。普通/ghost/disabled不再向子Frame强写透明背景；最终root值由Avalonia原生属性/Style优先级决定。默认线宽0，BorderColorDisabled只有在应用请求边框时可见；模板、布局和命中不通过代码回写属性实现。

### Custom 尺寸与原生优先级

Custom 的高度、字号、留白及普通/仅图标指标使用基础 Setter；仅图标回退由类型化 MultiBinding 选择，三档预设保持独立。未配置的 Custom 高度仍取中档；大字与大留白配方应同时明确 Height（需要自然测量时设为 Auto），避免固定高度裁切内容。
