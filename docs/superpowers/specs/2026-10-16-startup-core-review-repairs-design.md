# 启动重构终审与内核问题修复设计

日期：2026-10-16。输入为已实施但未提交的启动步骤 1–6，以及 2026-10-16 全局只读审查。
用户已明确要求修复审查发现的全部具体问题。本设计不重新选择启动架构，不修改既有公共 API、主题键、
控件模板或默认 Splash 策略；只恢复原本承诺的行为、生命周期和预算约束。

## 共同契约

- 所有应用、包、主题和字体资源必须有单一所有者与可验证释放路径。错误回滚不能留下部分发布状态。
- 数据清单与 AOT TypeMap 仍为纯元数据；不得以反射扫描、未用控件 CLR 根或后台 UI 对象创建解决问题。
- 控件主题与可见外观不因优化而变化。隐藏或脱离有效可见区域的持续视觉工作必须停止，重新显示应恢复。
- 修复前以已有或临时测试证明原问题；测试临时优先，完成后清理。最终只跑受影响模块、真实主题资产与必要的 AOT/Browser 发布；不运行未经请求的全量回归。
- 当前 `release/6.0` 主 checkout 承载本轮所有未提交启动改动，不能从 HEAD 建一个缺少这些输入的工作树替代。保留全部原有脏改动，不提交、amend 或 rebase。

## 1. 包钩子和启动事务

公开控制描述、语义或资源的实际消费，在返回给调用者之前必须兑现所属包一次性的 `OnFirstUse`；
元数据校验仍不触发钩子。初始启动的自有服务工厂/Attach 与应用 initializer、运行时追加服务 Attach、
以及包 `OnCommit` 中的跨包消费都不得通过尚未装入 context 的静默返回绕过它。仅构造服务的 Factory
若在应用 scope 挂接前实际消费包，必须在 descriptor 返回前明确失败；服务 Attach 及之后的消费可正常触发钩子。

同一包的 `OnCommit` 在 `OnFirstUse` 之前执行；跨包调用的排序必须确定，重入/环依赖明确失败且事务回滚。
context 必须对所有已启用包可用，失败时释放已拥有对象并保留原错误；成功发布后仍只执行每个钩子一次。
如果初始主题构建后、ApplicationScope 创建前的服务工厂失败，ThemeManager 及包索引也必须释放。

## 2. 编译主题严格要求

编译主题显式声明的每个 Control 都要求当前应用**实际启用且已选中**同身份/owner 的控件。
后台“仅全局”准备仍跳过控件层校验；正式提交或主题选择时，对所有显式要求先用纯索引元数据检查缺失、owner 与重复身份，
再保持具体 descriptor/Own Token 的首次使用绑定。已引用但未启用的包不能使要求变成可选项。
手写 CompiledThemeProgram 与生成主题遵守同一语义；动态 XML 的既有严格语义不变。

## 3. 惰性主题内存和复用

已发布的冷 Control cell 只能强持有该控件稳定入口、需要的配置和共享全局输入，不能保留整个历史
ThemeSchemaRegistry/StartupPackageIndex。反复追加包时旧索引代可被收集，既有 slot/已物化值保持不变。

缓存预算必须计入框架已知、被 deferred merge closure 或键保留的规范化控件覆盖值及已物化值；
不得为计费执行用户回调或强制物化所有控件。未知用户闭包内部图只按现有保守策略处理。
只改变控件 A 的配置且全局输入不变时，不应无谓丢弃已物化且未改变的控件 B 结果；
性能改法不能引入跨快照强引用链或提前物化整个控件表。

## 4. 其他内核所有权和绑定

字体包的应用级租约不能覆盖、释放或删除同一 URI 下由保留的 `WithXxxFont` 官方入口拥有的集合；
Avalonia `FontManager` 以 URI 替换和移除，故不能只靠 URI 引用计数推断实例所有权。
官方字体入口需在同一所有权模型下工作；宿主之后任意外部替换时，旧租约释放不得删除新实例。
宿主在官方入口之前直接占用 AtomUI 保留 URI 的第三方集合无法通过公开 FontManager API 查询实例身份，
属于明确的 URI 冲突，不靠 AOT 不安全的私有字段反射暗中处理。

省略 theme variant 的全局资源 observable 必须跟随应用实际变体变化；显式传入 variant 才固定。
非 Control `AvaloniaObject` 的 TokenResourceBinder 路径须兑现调用者的 converter 与 BindingPriority，并遵守 scoped
IResourceHost 优先、应用资源兜底及绑定释放契约。

MotionActor detach 释放可变 Transform 订阅；再次 attach 同一 Transform 时恢复。若 `MotionTransform` 和
`MotionTransformOperations` 同时存在，只有实际生效的优先属性决定矩阵并收到后续 Changed 更新。

## 5. Splash、主窗口和发布工具

Splash 不确定进度条仅在有效可见、挂载且启用时要求下一合成帧。错误态主题隐藏、祖先隐藏、detach 后停止；
恢复可见时按当前状态继续，默认主题、布局和动画外观不变。

主窗体首帧前关闭或启动取消时，首帧等待须立即结束，不应继续等 3 秒超时；状态仍为 Canceled，
Splash 正常关闭，不把已关闭窗口伪记为成功首帧。

Gallery 发布脚本在任何递归删除前验证所有参数及规范化输出根；拒绝文件系统根、用户家目录、仓库根/祖先和
构建输入目录，并限制递归清理到明确的本次发布目录。非法路径不得触发删除、restore 或 publish。

后续收益伪装成首次 JIT；涉及这些修复的性能路径只在同条件采样能证明时声明收益。
