# 多设计语言动效与替换契约

**目标规范草案 v0.1 · 2026-11-27。** 本文细化控件正式规范 v1.0 第三章的替换与验收要求。InteractionEffect、MotionScheme、MotionResource 和 PlacementMotionContext 为目标架构中的契约；已发布实现与目标能力分别取证。[控件设计规范](../../../engineering/development/multi-language-control-contracts.md) · [现行动效系统](overview.md)

## 1. 所有权与替换单位

控件决定用户做了什么、是否允许该操作、何时发布业务状态或事件。语言决定该状态或操作怎样呈现。模板提供真实目标、裁切边界与层叠位置。播放设施持有运行请求、时钟连接和释放责任。默认控件、默认动效及 Ant Design 取值的组合以复现对应 Ant Design 体验为目标。

**最小替换单位是控件明确开放的一种动效用途。** 例如应用可以为一个按钮替换激活反馈，仍沿用该按钮的悬停过渡、该语言的弹层轨迹和原有命令。该用途由所属控件包或公共基元声明类型化身份、触发条件、上下文类型、执行形式、有效终态、重入方式、禁用行为和支持的模板能力。维持一套公共业务 API。颜色、时长、缓动等标量差异先采用 Token 或已有属性。

| 用途 | 执行路径 | 覆盖范围及边界 |
| --- | --- | --- |
| 悬停、按下、选中等属性过渡 | ControlTheme 的 style setter、Avalonia Transitions、TokenTransitions | 可换参数或编译的过渡定义。关闭后立即呈现当前有效属性。Transitions 在 style setter 中声明，模板部件形态变化仍由模板负责 |
| 弹层开闭、内容展开等有限过程 | 现有 AbstractMotion、MotionBuilder、MotionPlayback 和布局能力 | 优先复用 OpenMotion、CloseMotion 或既有 Enter/Leave。按真实目标准备一次，完成结果交给控件核对最新意图。语言覆盖不取得打开或关闭物理宿主的权力 |
| 点击波浪、按压着色等瞬时反馈 | InteractionEffect 两阶段协议及所在表面的按需装饰宿主 | 支持外轮廓波浪、内部裁切扩散、纯颜色反馈或显式无效果。宿主实行同一触发协议，装饰呈现不参与命中、Tab 导航及业务事件 |
| Spin、Skeleton 等持续状态 | 原有专用后端与 MotionGate 或等价生命周期控制 | 定义提供循环呈现和静态替代。控件拥有忙碌状态。脱离、不可见或停用时停止帧工作，重启只依据当前状态。持续动画不占用有限 Motion 的完成任务 |

对同一目标，保留现有显式 Motion 的单一请求所有权。同一组并行动作使用既有组合能力。不同执行路径若可能写同一视觉属性，模板协议必须指定唯一写入方。例如弹层位移和按钮装饰可以使用不同目标；不得让 AXAML 过渡和显式播放同时争写同一目标的不透明度。无需为每个槽位新建视觉节点。

## 2. 来源、解析与登记

每个有真实消费者的开放槽位必须能区分三种配置。简单差异用现有标量或主题解决；只有局部切换效果种类、而无需整套模板时才新增用途。无活动效果时不得为未来扩展常驻节点或运行会话。

| 配置 | 结果 |
| --- | --- |
| 未提供 / Inherit | 查下一有效来源 |
| 显式关闭 / None | 停止查找该槽位，执行其无动画终态或静态反馈 |
| 指定定义 | 校验类型、版本和目标能力。准备成功后由所属执行路径接管 |

1. 在当前 ThemeContext 中按控件身份与槽位解析语言默认。对可选的动效或反馈逐槽沿 LanguageTokenType 链由近及远解析，未命中采用控件包默认。必需的 Token 规则按原覆盖校验执行，不能用 Ant 的独立语言取值包填补缺项；完整行为对象的选择见主规范第 4.2 节。独立语言没有隐式的跨语言取值回退。未覆盖的默认动效仍读取当前作用域的有效 Token。派生语言可逐项省略或明确关闭。
2. 应用可以在作用域配置中覆盖某控件的槽位，最近的明确覆盖生效。对已有 OpenMotion/CloseMotion 等属性，解析结果只作为主题默认接入。实例值、绑定、应用样式和模板按 Avalonia 自身优先级得到有效值。显式 null 延续既有无动效语义，ClearValue 移除该来源后回到当前有效配置。控件主题首次装载遵循主规范第 5.1 节已联合验证的顺序，应用 Style 与父模板的有效 Theme 优先，隐式主题按作用域首次取用。既有开闭属性的默认则由 ControlTheme Setter 读取 MotionResource；清除本地值可先回到应用样式，再按当前作用域取框架缺省。只换模板时仍应能消费同一槽位。[主规范 §5.1](../../../engineering/development/multi-language-control-contracts.md#51-在第一次消费时选定实现)
3. 总动效禁用、显式禁用和目标不能安全播放，对已经解析的定义进行最终约束。禁用时完成业务所需终态，持续反馈显示静态忙碌标志。降低动效偏好可选择短渐变或静态方案，不能被语言强行提升为正常强度。系统偏好接入与宿主显式设置的映射须在对应平台验证后声明支持。
4. 时长、曲线和颜色等值进入取值包；编译的呈现定义、工厂或模板进入语言的可选实现贡献。使用现有四类包结构。可选实现贡献由对应控件包的 .Themes.<Lang> 声明。选择沿 LanguageTokenType 的单继承链逐项回退；应用以整套语言切换，局部属性仍允许明确覆盖。复用显式登记、作用域事务与版本校验。生成登记片段按控件可达性关联槽位、版本、宿主能力、依赖与工厂。MotionScheme 定义按 MotionSlot 组织，不反向引用具体控件 CLR 类型。Token 序列化不携带可执行代码。重复冲突、版本不兼容和缺少必要能力须诊断。语言和应用都可复用公开入口，框架自带效果不享有独占的几何输入。

独立覆盖的消费示意如下。登记本身不会启动播放。

在 v1.0 的目标 API 下，Select 默认主题以 `<Setter Property="OpenMotion" Value="{atom:MotionResource SelectOpen}" />` 消费语言定义，CloseMotion 独立读取 SelectClose。外部语言可以只登记 SelectOpen；应用在某个实例上写 `OpenMotion="{x:Null}"` 即可关闭该方向。位置感知的定义经 IPlacementAwareMotion 取得本次 PlacementMotionContext；普通 Fade 等定义无需付出锚点准备成本。动态使用 OpenMotion 时仍须遵守既有 DurationOverride、显式 Duration 和有效开关的语义。

| 来源与操作 | 按钮激活反馈 | 弹层打开 | 可观察结果 |
| --- | --- | --- | --- |
| Ant Design 默认 | Ant 波浪定义 | 控件默认轨迹 | 以锁定的 Ant 组件基线验收 |
| 示例语言只登记激活反馈 | 内部扩散定义 | 继承 | 原按钮和命令保持相同，新效果读取该次命中的局部坐标 |
| 局部作用域显式关闭激活反馈 | None | 继承 | 子树无点击装饰，业务点击正常；同窗相邻作用域继续使用其定义 |
| 应用给 Select 的 OpenMotion 设置自定义轨迹再清除 | 无关联 | 应用定义，清除后恢复语言定义 | 更换语言不会改写用户绑定或重复触发 Opened |

## 3. 反馈宿主与波浪试点

InteractionEffect 取代现有按钮模板的常驻波浪节点。默认从目标所在表面最近的 T2 AdornerLayer 按需租用装饰节点，结束时摘除。静置按钮不占一个反馈节点。外轮廓允许超出按钮边界，仍须尊重祖先视口和提升表面的可见边界；宿主把祖先的有效 Clip、滚动视口和当前装饰表面换算到同一坐标系求交；滚动、缩放、变换或换表面时更新。可见交集为空时不绘制，目标脱离时归还租约。内扩散按本次目标轮廓裁切。控件将一次合法的反馈机会交给宿主，附带类型化的只读快照。最低信息为触发阶段、输入来源、可选局部位置、实际绘制尺寸、有效圆角、渲染缩放、颜色角色及作用域版本。指针使用本次输入位置，键盘或自动化使用该定义声明的无坐标策略。延迟播放前复核目标与版本。不得通过全局读鼠标位置补造起点。

语言实现通过 OnPressStarted、OnActivated 与受宿主管理的绘制/合成服务产生反馈，第三方不得直接依赖内部 MotionFrameDriver 或 MotionCompositionTransform。首个试点至少表达有独立时长和曲线的轮廓扩张、透明度，以及有起点和内圆角裁切的填充扩散。模板声明可用的前景/背景装饰面和内外裁切能力。使用受宿主管理、无输入能力的绘制目标或模板部件，播放层拥有失效、取消与释放。绘制扩展接收快照和当前帧的呈现值，不接管业务事件、控件树、私有时钟或任意应用属性。若某种效果确需新的几何能力，先版本化该用途的宿主协议，再登记依赖它的实现。

触发阶段必须与业务操作分开。Ant 默认 click、可配置的按下/松开，和面向键盘的激活都应有明确映射。由控件报告已识别的阶段，其中“激活”只在控件确认该操作时发出。一个效果只消费其声明的阶段，按下加激活不会无意播放两次。被取消的手势可以结束已开始的按压反馈，但不能产生一次成功激活反馈。按钮、CheckBox 和 Switch 的现有触发条件分别核对，不能一次改成同一事件处理器。

**恰好一次的会话交接。** OnPressStarted 返回的会话持有 PlayDecoration 提供的 IDecorationEffectLease。入场结束后可按住保持。TryBeginExit(exit) 只允许在同一节点从当前呈现值接续一次，返回 true 时尾动画交给宿主。迟到、重复或已取消的调用返回 false，旧句柄 Dispose 不取消已接管的尾动画。释放由控件判定是否激活，可正常结束的会话调用一次 Complete(activated)，捕获丢失、换根、切语言或脱离时改为 Cancel。两条终止路径互斥，Dispose 可重复并清除剩余资源。OnActivated 表达独立的成功激活阶段；既消费按下又消费激活的实现以同一操作身份关联，不能再启动第二道相同反馈。键盘激活允许无按下会话，控件以正常命令路径产生一次反馈。

**必须覆盖没有返回会话的尾动画。** OnActivated 返回 void，Ant 波浪在该调用返回后还在播放。两种回调的公开 Playback 提供 PlayDecoration 和 PlayOnSurface，签名由主规范第 3.3 节统一定义。每次调用先登记目标、操作、代次与唯一租约，再创建或连接视觉并启动；装饰句柄扩展 IDisposable 并只增加 TryBeginExit；表面播放仍返回 IDisposable。即使调用者丢弃句柄，宿主仍负责自然完成、失败与撤销。工厂内重入切换时须释放部分连接，已失效的上下文不能租用新节点。收束旧语言、换模板或关闭页面时既取消按下会话，也收回这些激活后租约。宿主先使租约失效并停止呈现，取消在途播放，待其结束后 Reset 并清理。第三方工厂创建的节点按次释放。只有框架能确定重配和清理方式的内置节点才可归池，归池前清除目标、画刷、Clip、变换、合成动画及订阅。重复完成或迟到回调必须比对租约身份，不能把已借给下一次点击的节点摘走。

**迁移边界。** 按控件规范 v1.0，将 IWaveSpiritAwareControl、IsWaveSpiritEnabled、EnableWaveSpirit 迁移到 IInteractionEffectAwareControl、IsInteractionEffectEnabled、EnableInteractionEffect，不保留旧名别名，需写 API Break 及配置迁移说明。必须审查旧布尔值的意图：若要关闭所有交互装饰，写新开关 false；若要取消 Ant 波浪而采用其他反馈，保持通用开关启用并选择其他效果。原有波浪指标的归零行为只用于对应波浪定义，不应抹去替换效果的输入。

## 4. 定义、接管与切换

语言贡献可共享的是静态工厂、不可变描述和纯曲线。现有 AbstractMotion 具有可写配置，准备时须冻结本次输入，共享工厂不得在运行中改写另一个目标采用的对象。目标、取消令牌、计时器和订阅归活动请求所有。按 Application、作用域有效选择和模板能力解析可复用结果；热路径不得反射、按名称查找定义或遍历控件树。

| 现场 | 必须交付的结果 |
| --- | --- |
| 同目标收到反向或新请求 | 有限 Motion 沿用先准备再接管、请求身份与相容通道重新定向。Ant 重复激活与已按下的 ripple 按各自规格验证；重叠绘制用有界租约并定义回收顺序。按压缩放要与已有 RenderTransform、弹层变换及命中保持一致。没有独占呈现通道时按已声明的降级路径稳定结束，不能覆盖应用的变换或取消宿主的开闭请求 |
| 完整语言切换 | 与 Token、模板、交互策略同一作用域代次提交。提交引发的装饰过渡直接收束到新基线，避免首帧闪烁。正在运行且受影响的点击装饰停止并清除，切换后不重播旧点击。活动 IME 若会因控件自身或祖先重套模板而丢失编辑宿主，按主规范第 5.2 节对最小可隔离边界保留完整旧呈现与输入版本。同一次筛选或键盘选择的已开应用 Popup 读取同一受保护快照和明暗变体，边界之外正常提交。无关作用域中既有请求不因角色解析而被取消 |
| 已开始打开/关闭的 Popup | 业务意图由 owner 保存。目标与定义仍兼容时可按当前请求完成；需换宿主或定义时先使旧请求失效，按当前打开意图建立新呈现或稳定收敛。只有最新请求、宿主及关闭意图一致时才物理关闭一次。切换不能导致弹层重新打开或重复触发事件 |
| 持续反馈与主题提交 | 提交后若仍忙碌且 gate 开启，仅新呈现运行；不可见或禁用时无活跃时钟。旧合成会话由 owner 停止。现有 MotionSettle 仅收束其覆盖窗口内的新动画，不能用它替代旧会话注销或专用合成后端交接 |
| 缺失、故障与脱离 | 未登记按继承处理，显式 None 直接收敛。已登记但无效的定义按提交阶段报告错误。播放期故障释放该次呈现，恢复应用底值或业务意图决定的稳定终态；不得重放输入。NotReady 由 owner 在真实就绪点有限重试或直接收敛。重套模板、容器回收、弹层关闭均使旧回调失效 |

过渡的最终值由状态和样式拥有。显式 Motion 使用其 FillMode 与现有终态释放契约，取消时须恢复最新底值和绑定。装饰反馈完成后撤掉本次绘制。持续反馈须能停止、在条件恢复时按定义重新启动。总开关在播放中关闭时也须执行上述各自的稳定路径。[播放协议](playback-and-lifecycle.md) · [主题提交收束边界](theme-commit-settle.md) · [弹层宿主协议](popup-motion.md)

## 状态通道与弹簧值契约

状态微过渡与组件开闭分别求值。Ant Design 6.7.0 横向 Menu 的背景/边框采用 Slow（300 ms），普通 Button 状态采用 Mid（200 ms）及其约定缓动，Button 特定通道仍可采用 Slow。StateTransitionDuration/Easing 仅作配方选取的来源。PrimeNG Nora 可将微状态通道归零而保留 Select 的编排时长。优先用现有 Fast/Mid/Slow 和控件取值规则，只有独立覆盖确有需求的参数才增加词汇。

Shadcn 的内置开闭槽位与 PrimeNG 的选择器、菜单和浮层槽位读取 `MotionDurationEnter`、`MotionDurationLeave`。PrimeNG Dialog 使用控件视图的 Slow/Mid，ToolTip 使用自身的 `MotionDuration`。共享时长可写在主题 XML 的根 `<Tokens>` 或控件级 `<Control>/<Tokens>` 中。ToolTip 的 `MotionDuration` 写在控件级。内置定义在播放准备时从有效作用域取值，定位翻转保留定义选项。显式播放覆写、目标的 `Motion.DurationOverride` 和选中定义的显式 `Duration` 优先。未解析的时长 Token 回退到宿主共同默认，显式零直接得到终态。

`MotionEasingEnter`、`MotionEasingLeave` 允许覆盖上述 Shadcn 和 PrimeNG 槽位的曲线，空值使用轨迹原有曲线。专用属性过渡使用 `TokenTransitions.Easing`，接入 `StateTransitionEasingOverride` 的通道在该值为空时使用模板原曲线。Button 按下位移使用独立的 `StateTransitionDurationPress`。普通 Ant 波浪保留原扩张时长来源，淡出读 `WaveFadeDuration`，曲线由可选的 `WaveEasing` 提供。

弹簧直接采用 Avalonia 的 SpringEasing 和现有四参数编译表示，不增设同名包装类型。动态取值转换和构建期 worker 须复用同一解析规则，接受格式化器生成的 Spring(mass,stiffness,damping,initialVelocity)，以不依赖区域设置的数值格式往返。类型/参数是值身份；缓存不得以可变 Easing 对象引用为键。四参数均须有限，Mass > 0、Stiffness > 0、Damping ≥ 0。读取与快照复制复用已有 CloneForConsumer / TryCopy。在拥有实例的执行线程采样可变 Easing；若新后端确需跨线程共享，须证明安全发布与独占，或从不可变参数独立创建。不得为所有曲线引入启动预热。现有其他 easing 拼写仍须兼容。

**原始曲线与有限播放终态分别验收。** 原始 Ease(1) 可以超过 1。Motion 在时长耗尽时写入轨迹终值。对要求平滑结束的配方，须按通道单位预定可接受残差，比较终点前采样值与强制终值。超限时拒绝该配方或调整参数，保持中途超调及两种取值路径的曲线语义。非有限输出在播放失败边界清理。

## 5. 合规验收

以正式规范 v1.0 的两维 TokenTransitions（Duration/Easing）、MotionScheme、IPlacementAwareMotion 与两阶段 InteractionEffect 为公共消费入口。测试覆盖默认/自定义行为、默认/语言模板、默认/语言动效的正交组合。额外覆盖零时长颜色过渡与正常弹层编排同时生效；缓存键纳入完整时长与缓动参数，避免不同曲线误共享或可变对象污染其他作用域。

- **公开可替换。** 用无友元权限的外部 NuGet 消费包提供一种有限轨迹和一种装饰反馈。只登记反馈即可在默认模板中生效。单独更换合规模板并沿用默认效果也须通过。验证早松手、长按、重复退出、切换时取消、迟到释放；两种贡献同时生效、None、清除及错误协议诊断分别检查。外部工厂携带不同的当次位置与画刷，后次不得沿用前次输入。
- **弹簧端到端。** 同一文本分别走真实动态 ThemeConfig/主题文件与发布包编译、独立消费，再读快照。用 Spring(1,120,12,0.5) 核对实际类型、四参数精确一致，以及 0、0.25、0.5、0.75、1 的有限输出与参考曲线差值不大于 1e-12（同后端同配置）。修改输入对象后旧快照不变；仅改刚度时产生新缓存键。错误参数必须诊断，不能静默改成另一条曲线。完成已有包格式兼容与受影响 AOT 消费，才冻结该能力。
- **Ant Design 基线。** 锁定对应版本，分别复现一般与 quick 波浪。采样扩张与淡出的起点、中间点、终点、总时长、范围及曲线，再测重复点击、取消、禁用、键盘和变体适用性。默认触发和可配置触发分开对标。网页与桌面的光栅差异按预先约定的几何/透明度判据验收。
- **生命周期。** 同窗双作用域、弹层开→关→开、播放中切语言、延时未开始即脱离、重套模板、关闭总动效、隐藏循环和恢复全部有可失败的结果断言。控件、旧部件与运行资源可回收；点击、命令、打开和关闭次数符合原控件契约。
- **成本。** 复用真实 Button 和 Popup 页面，比较未配置、None、Ant 默认和外部替换。记录冷首次使用、常驻节点和订阅、每次点击分配、活动帧分配/耗时和空闲帧工作。None 不创建活动请求、画笔或帧订阅。控件数量放大后抽查帧尾延迟。区分 Headless、原生渲染回调与显示器实际呈现。按主规范第 6.2 节执行 NativeAOT 负向闭包、Token-only/Style-only 两份独立正例，以及真实控件切语言后的模板命中与动效完成断言。性能收益及跨平台支持只在取得相应证据后报告。
