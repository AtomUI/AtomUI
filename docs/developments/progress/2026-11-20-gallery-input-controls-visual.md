# Select 标签高度、Switch 按压轮廓、Mentions 焦点环和 TimePicker 间距

在 `bugfix/shadcn` 的 1300 × 900 DIP Gallery 使用真实页面和控件。临时驱动通过框架指针事件选中选项、点击删除按钮、按住及释放开关，并在窗口编号确定后捕获 macOS 2× 原生帧。Select 矩阵和 Switch 前后对照另外使用 2× Avalonia Headless + Skia。

| 场景 | 验收结果 |
| --- | --- |
| Select `Two-way binding / SelectedOptions` 与 `Tags` | Luma、Nova、Vega、Maia、Lyra、Mira、Sera、Rhea × 浅色和深色 × Small、Middle、Large × 两种模式，共 96 组 Skia。macOS 另测 Luma 浅色中号、Nova 深色小号、Rhea 浅色大号的两种模式，共 6 组。实测单行高度 26–44 DIP，各组合选中、关闭弹层、删除及空选恢复均严格等高，宽场景的布局采样也只出现原高度。 |
| Select 标签换行与逐个删除 | 同实例缩到 140 DIP 后选入真实候选项。多选为 3 行，Tags 为 2 或 4 行，实际高度范围分别为 72–138、74–164 DIP。逐个删除只在少一行时回落，最后一行和清空均回到原高。首轮并行中 Vega 浅色中号 Tags 有一次点击未完成，随后单独用同路径复播两次通过，最后一次同时确认了关闭按钮真实命中与截图。Select 通过现有实现。 |
| Select 像素检错 | 原生和 Skia 全帧同状态复拍均为零像素差。1 DIP 纵移在两端均被检测，恢复后均为零像素差。整矩阵检查上下边框颜色、位置及芯片在输入框内的布局，已查看 8 风格的代表截图。 |
| Ant Design ToggleSwitch Basic | Skia 修复前的按压增宽在中线约 10 物理像素、近顶横截线仅 5 像素。修复后原生实测开、关两端分别在中线和近顶横截线增宽 10 / 11 物理像素，靠轨道外侧的端点保持锚定。滑块中段为水平直边。Skia 采到双向释放位移动画，Shadcn 保持圆形按压。自定义模板中的旧滑块在替换后解除绑定。 |
| Mentions Basic `@afc163` | 旧输入框轮廓的 3 DIP 阴影已存在，428 × 36 DIP 同尺寸的 Mentions 根裁剪使上下外侧的 3 × 80 Skia 采样带中像素差为 0/0。仅切换根裁剪即变为 240/240，复位后归零。根模板修复后，原生 Shadcn Luma 浅色和深色的四边各测到 6 个连续物理像素，保持 3 DIP，圆弧完整。外扩焦点环区域的命中范围没有增加。 |
| Mentions 其余示例与交互 | 页面实际物化 23 个 Mentions。在 1020 × 800 DIP 的 Skia Gallery 检查自定义高度、错误、自动高度、固定多行、只读与禁用。启用样例的上、下焦点带均完整，禁用态无焦点带。Gallery 外层滚轮从 0 滚到 150 DIP。固定多行经输入填充 20 行，内部视口 284 × 66 DIP、内容 284 × 440 DIP，滚轮移动内部到 274 DIP 时外层保持 1303 DIP。候选弹层可通过真实输入打开，Escape 关闭后编辑器仍持有焦点。 |
| Shadcn TimePicker Basic，分钟 `00` 已选中、`01` 悬停 | 2× Skia 原场景在 Luma 浅、深色均从 0 变为 4 个物理像素间距，对应 2 DIP。实测行高始终为 32 DIP，列视口 56 × 256 DIP，弹层 191 × 325 DIP。左、中、右和贴近上边缘的点击区域可命中；点击 `01` 上边缘、确认后时间为 `00:01:00`。滚轮偏移往返 1920 → 1970 → 1920，键盘 `00 → 59 → 00` 循环通过。Ant Design 对照保留原有 28 DIP 行高和背景。 |

原生与 Skia 的关键截图已阅，临时驱动、用例和取证媒体均已审计并清理。清理后定向测试通过 Select 75 项、Switch 18 项（控件 14，Gallery 4）、Mentions 48 项（控件 26，渲染 22）、TimePicker 72 项（控件 64，Gallery 2，渲染 6）。`git diff --check` 通过。
