# AtomUI 6.2.1 API 变更示例

AtomUI 6.2.1 在对齐 Ant Design 快速跳页行为的同时，有意调整 Pagination 的默认导航窗口和 Semantic Part marker
数量。对已实现导航容器池做快照、自动化或样式依赖的应用，需要按本文迁移。

English version: [AtomUI 6.2.1 API Change Examples](6.2.1-api-changes.md)。

## 快速对照

| 领域 | 6.2.0 行为 | 6.2.1 迁移 |
| --- | --- | --- |
| Pagination 导航池 | 固定 11 个 `PaginationNavItem` 容器，省略号单元格不可交互 | 固定 9 个容器：上一页 + 7 个中间槽位 + 下一页；依赖旧数量的快照或自动化需更新 |
| Pagination 快速跳页 | 省略号单元格不执行导航 | `JumpPrevious` / `JumpNext` 默认跳转 5 页，`IsShowLessItems=true` 时跳转 3 页；设置 `IsShowPrevNextJumpers=false` 可隐藏快速跳页操作 |
| Pagination Semantic Part | 运行时 `item` marker 池跟随 11 个容器 | 运行时池跟随 9 个容器；快速跳页项仍明确排除在 `PaginationItemStyle` 匹配之外 |

## Pagination：更新导航窗口预期

Pagination 现在使用固定的 9 容器导航池。首尾容器继续表示上一页和下一页操作；中间 7 个槽位在页码指示项与
`JumpPrevious` / `JumpNext` 操作之间复用。快速跳页操作支持指针与 Enter 键触发。

导航模型默认规则如下：

- `IsShowLessItems=false`：最多 7 个中间槽位，快速跳转 5 页。
- `IsShowLessItems=true`：最多 5 个中间槽位，快速跳转 3 页。
- `IsShowPrevNextJumpers=true`：页码窗口需要时显示快速跳页操作。
- `IsShowPrevNextJumpers=false`：页码窗口不显示快速跳页操作。

### 需要更新的 6.2.0 假设

检查已实现容器的测试或自动化可能仍期待 11 个 `PaginationNavItem` 实例，或对应数量的 Semantic Part marker 池。
请把这些预期更新为 9。应用应继续通过生成的 `PaginationItemStyle` 定制页码、上一页与下一页项；
`JumpPrevious` 与 `JumpNext` 有意不携带 `semantic-item` marker。

```xml
<Style Selector="atom|Pagination">
    <atom:PaginationItemStyle x:SetterTargetType="ContentControl">
        <Setter Property="CornerRadius" Value="999" />
    </atom:PaginationItemStyle>
</Style>
```

不要依赖 internal `PaginationNavItem` 类型、容器索引或隐藏容器数量。请改用 `CurrentPage`、`PageSize`、
`IsShowLessItems`、`IsShowPrevNextJumpers` 以及生成的 Semantic Part 样式入口。

### 选择 6.2.1 导航模式

```xml
<!-- 对齐 Ant Design 的默认窗口和 5 页跳转。 -->
<atom:Pagination Total="500"
                 CurrentPage="20"
                 IsShowPrevNextJumpers="True" />

<!-- 更紧凑的窗口和 3 页跳转。 -->
<atom:Pagination Total="500"
                 CurrentPage="20"
                 IsShowLessItems="True"
                 IsShowPrevNextJumpers="True" />

<!-- 仅显示页码，不显示快速跳页操作。 -->
<atom:Pagination Total="500"
                 CurrentPage="20"
                 IsShowPrevNextJumpers="False" />
```

6.2.1 不提供恢复精确 11 容器池的兼容开关。界面契约若依赖该内部实现形态，应暂时保留在 6.2.0，或先把依赖迁移到
Pagination 公开状态与 Semantic Part 样式，再升级至 6.2.1。
