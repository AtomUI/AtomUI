# AtomUI 6.3.0 迁移指南

[English](6.3.0-api-changes.md) · [更新日志](../../CHANGELOG.zh-CN.md#630)

本指南说明从 6.2.15 升级的改动。主题系统改为以**设计语言**组织：语言包（例如 `AtomUI.DesignLanguages.AntDesign`）
负责种子与全局推导，控件包只声明自己的 Token，每个控件包在每种语言下有一个取值包（例如
`AtomUI.Desktop.Controls.Themes.AntDesign`）写出控件取值。主题按语言、风格、明暗与密度选择。细节见[编写设计语言](../guides/theming/writing-design-languages.md)、
[主题定义 XML v2](../reference/theming/theme-definition-xml-v2.md) 与[编译主题包生成 ABI v4](../reference/theming/compiled-theme-abi-v4.md)。

与 6.2.15 相比，Ant Design 有意调整的取值见[新增 Token 与修正](#新增-token-与修正)。

## 速查

| 范围 | 6.2.15 | 现在 / 迁移 |
| --- | --- | --- |
| 启动 | `UseDesktopControls()`（以及 ColorPicker、DataGrid）自带 Ant Design 主题 | 显式启用语言：`UseAntDesign(language => language.AddDesktopControls())`；一种语言都没启用时启动抛出 "No design language is enabled; enable one (for example builder.UseAntDesign(...))." |
| 包 | Ant Design 公式在 `AtomUI.Core` 与各控件 Token 类里 | 新包 `AtomUI.DesignLanguages.AntDesign`、`AtomUI.Controls.Themes.AntDesign`、`AtomUI.Desktop.Controls.Themes.AntDesign`、`AtomUI.Desktop.Controls.ColorPicker.Themes.AntDesign`、`AtomUI.Desktop.Controls.DataGrid.Themes.AntDesign` |
| `ThemeAlgorithm` 与算法链 | 枚举 `Default` / `Dark` / `Compact`、`ThemeConfigBuilder.WithAlgorithms`、主题 XML 的 `<Algorithms>` | 删除。明暗（`ThemeAppearance`）、密度（`DesignDensity`）、风格（`DesignStyle`）、形态（`DesignIdiom`）是相互独立的参数 |
| 计算器 | `DefaultThemeVariantCalculator`、`DarkThemeVariantCalculator`、`CompactThemeVariantCalculator`、`AbstractThemeVariantCalculator`、`IThemeVariantCalculator`、`IThemeVariantCalculatorFactory`、`IThemeAlgorithm`、`ThemeAlgorithmAttribute`、`ThemeAlgorithmDescriptor`、`ThemeAppearanceEffect`、`ThemeAlgorithmTypeConverter` | 删除；Ant Design 的公式在 Ant Design 语言包里 |
| 色彩工具 | `AtomUI.Theme.Algorithms`（`PaletteGenerator`、`PresetPalettes`、`PresetPrimaryColor`、`PresetColorType`、`PaletteInfo`、`PaletteGenerateOption`、`ColorMap`） | 同名类型移到 `AtomUI.Theme.Derivation`，改 `using` 即可；同一命名空间新增公开的 `CalculatorUtils`、`FontSizeInfo`、`RadiusInfo` |
| `IThemeManager` | `AvailableThemes` | `Themes`（另列出每种已启用语言的隐式默认条目 `$<语言>`）；新增 `Languages`、`CurrentSelection`、`ApplyAsync(ThemeSelection)` |
| `ThemeCatalogReloadResult` | `AvailableThemes` | `Themes` |
| `ThemeInfo` | `(Id, Name, Appearance, IsDefault)` 及 `AccentColor` | `(Id, Name, Language)`，`init` 属性 `Style`、`Appearance`（可空）、`Density`、`LockedSeeds`、`SeedValues`（主题自己给出的可调种子值）、`AccentColor`、`IsLanguageDefault`；`IsDefault` 删除 |
| `ThemeConfig` / `ThemeConfigBuilder` | `Algorithms`、`WithAlgorithms(...)` | `Language`、`Style`、`Appearance`、`Density`、`Idiom`、`LanguageTokens`；`WithLanguage`、`WithStyle`、`WithAppearance`、`WithDensity`、`WithIdiom`、`WithLanguageToken` |
| `ControlAlgorithmMode` | 控件配置的四种控件算法模式 | 删除；控件级取值只替换该值，控件级种子或轴使该控件成为独立的求值单元 |
| 主题定义 XML | v1 | 只支持 v2；用 `dotnet msbuild -t:ConvertAtomUIThemeDefinitions -p:AtomUIThemeDefinitionInput=<目录> [-p:AtomUIThemeDefinitionOutput=<目录>]` 一次性换写 |
| 编译主题包 | ABI 1 | ABI 4；用当前生成器重新构建 |
| 控件 Token 类 | 多数为 `internal`，取值在 `CalculateTokenValues` 里计算 | `public partial`，只有声明；取值来自所用语言的取值包 |
| `SharedTokenResourceValue` | 公开 | 删除 |

## 启用设计语言

```csharp
// 以前（6.2.15）
builder.UseAtomUI(root => root
    .UseDesktopControls()
    .UseDesktopColorPicker()
    .UseDesktopDataGrid());

// 现在
using AtomUI.DesignLanguages.AntDesign;
using AtomUI.Desktop.Controls.Themes.AntDesign;   // AddDesktopControls, AddDesktopColorPicker, AddDesktopDataGrid

builder.UseAtomUI(root => root
    .UseDesktopControls()
    .UseDesktopColorPicker()
    .UseDesktopDataGrid()
    .UseAntDesign(language => language
        .AddDesktopControls()
        .AddDesktopColorPicker()
        .AddDesktopDataGrid()));
```

- `UseDesktopControls()`、`UseDesktopColorPicker()`、`UseDesktopDataGrid()` 照旧启用控件包。
- `UseAntDesign(...)` 启用语言及其官方主题（Daybreak Blue）。`Add*()` 只登记取值包，不启用控件包。
- 每个已启用的控件包在每种已启用的语言下都要有取值包；缺了的在启动时报错，消息写出缺少的取值包名。

## 选择主题

```csharp
// 以前
await themeManager.ApplyThemeAsync(new ThemeRequest("DaybreakBlue", config, ThemeTransitionReason.UserRequest));

// 现在：按语言与变体
await themeManager.ApplyAsync(
    ThemeSelection.Of("AntDesign")
        .WithAppearance(ThemeAppearance.Dark)
        .WithDensity(DesignDensity.Compact)
        .WithSeed("ColorPrimary", "#1677FF"));
```

- `ThemeSelection` 携带 `Language`、`Style`、可选的具名主题 `ThemeId`、`Appearance`（或 `FollowSystemAppearance()`）、
  `Density`、全局种子 `Seeds` 与语言种子 `LanguageSeeds`。`ThemeSelection.Of<TLanguage>()` 用语言类型代替 Id。
- `IThemeManager.Languages` 以 `DesignLanguageInfo`（`Id`、`Styles`、`DefaultStyle`、`Densities`、`Idioms`、
  `AdjustableSeeds`）列出每种已启用的语言；语言、风格、密度与品牌色菜单由它生成。
- 每种已启用的语言在主题目录里有隐式条目 `$<语言>`（`ThemeInfo.LanguageDefaultId`，标记 `IsLanguageDefault`），
  没有主题文件也能选中该语言。
- 未知的语言、主题或轴取值抛出 `ThemeSelectionException`。
- `ApplyThemeAsync(ThemeRequest)` 提交一份带完整运行时配置（含控件级取值）的主题请求。`IThemeManager.DEFAULT_THEME_ID` 已删除：
  核心不再写死任何语言的主题 id，改用 Ant Design 语言包的 `AntDesignThemes.DaybreakBlue`。
- `IThemeManagerBuilder.WithInitialTheme(ThemeSelection)` 设定启动时的选择。

- 主题目录事件处理程序改用 `ThemeCatalogChangedEventArgs.Themes`。读取当前主题状态时，从
  `ThemeState.Language` 和 `ThemeState.Variant` 获取语言和变体。自行构造状态时传入语言和 `DesignVariant`。
- C# 中使用 `ToolTip.PresetColor` 或 GalleryBase 的 `PaletteMetaItem` 时，从 `AtomUI.Theme.Derivation` 引用
  迁移后的 `PresetColorType` 和 `PresetPrimaryColor`，然后重新编译。

## 主题配置

`ThemeConfig.Algorithms` 与 `ThemeConfigBuilder.WithAlgorithms` 已删除，直接写变体：

```csharp
// 以前
new ThemeConfigBuilder().WithAlgorithms(ThemeAlgorithm.Default, ThemeAlgorithm.Dark, ThemeAlgorithm.Compact).Build();

// 现在
new ThemeConfigBuilder()
    .WithAppearance(ThemeAppearance.Dark)
    .WithDensity(DesignDensity.Compact)
    .Build();
```

每个轴各自从外层作用域继承，内层不再整体替换算法链。显式取值在任何推导运行之前就固定下来：主题或配置给出的值不会被
覆盖，由它派生的值跟着它变。

## 主题定义 XML v2

主题文件改用 v2 格式。同一语言、同一风格的四个文件（浅色、深色、紧凑、深色紧凑）合为一个文件，差异写在 `<When>` 段里。
`<Algorithms>`、`IsDefault`、`DesignLanguage`、`BrandColor`、`NeutralColor` 已删除：`<Theme>` 上的 `Language` 与 `Style`
给出分组，Token 上的 `Locked` 说明哪些值用户不能替换。v1 文件不再读取；用户主题目录里的 v1 文件报 `ATMTHM1004` 并
给出换写命令，换写之前该目录不生效。一次性换写：

```bash
dotnet msbuild -t:ConvertAtomUIThemeDefinitions -p:AtomUIThemeDefinitionInput=<目录>
```

命令缺省就地改写，并删除被合并的变体文件；另可用 `-p:AtomUIThemeDefinitionOutput=<目录>` 输出到别处。见
[主题定义 XML v2](../reference/theming/theme-definition-xml-v2.md) 第 14 节。

## 编译主题包

生成器产出编译主题 ABI 4，记录包所需的语言（清单作用域 `language`）。按 ABI 1 构建的包不再加载，需重新构建。

## 控件 Token 类与第三方控件包

`AtomUI.Controls`、`AtomUI.Desktop.Controls`、ColorPicker、DataGrid 的全部控件 Token 类为 `public partial`，只含声明。
`CalculateTokenValues` 与在构造函数里赋值的写法已删除；Ant Design 的取值原样移入各 Ant Design 取值包的
`[ControlTokenRule]` 类。

第三方控件包声明自己的 Token，并为支持的每种语言发布一个取值包：

```csharp
// 控件包：只有声明
[ControlDesignToken]
public sealed partial class RatingToken : AbstractControlDesignToken
{
    public partial double StarSize { get; set; }
}

// 取值包（例如 Acme.Controls.Themes.AntDesign）
[ControlTokenRule]
internal sealed class AntDesignRatingTokenRule : IControlTokenRule<AntDesignToken, RatingToken>
{
    public void Apply(in TokenEvaluationContext<AntDesignToken> context, ControlTokenTarget<RatingToken> target)
    {
        target.Own.StarSize = target.Global.ControlHeight * 0.625;
    }
}
```

- Token 类或 Token 属性不是 `partial` 时报 `ATOMUIGEN049`。
- 推导必须写全所属类的每个 Token（`ATOMUIGEN050`），不得先读后写（`ATOMUIGEN051`）。对 `target.Global` 的写入是控件
  作用域内对 Map 与 Alias Token 的覆盖；写种子会抛出。
- 生成器为控件包产出 `[assembly: TokenSchemaDigest]`，为取值包产出 `[assembly: CoversTokenSchema]`。取值包若针对另一
  版本的控件 Token 构建，启动时被拒绝，消息写出两个包名与两个摘要。
- 见[编写设计语言](../guides/theming/writing-design-languages.md)第 4 节与[第三方控件包](../guides/theming/third-party-control-packages.md)。

## 编写设计语言

语言是一个派生自 `DesignLanguage<TLanguageToken>`、标注 `[DesignLanguage]` 的类：声明 `Axes`（`DesignLanguageAxes`：
风格、明暗、密度、形态、可调种子），实现 `DefineSeeds`、`DeriveLanguage` 与 `DeriveGlobal`。语言 Token 派生自
`LanguageDesignToken` 并标注 `[LanguageDesignToken]`。取值包实现 `IControlTokenRule<TLanguageToken, TToken>`；查找沿语言
Token 的继承链进行，所以派生语言继承其基础语言的控件取值，只覆盖不同之处。契约测试库 `AtomUI.Theme.ContractTests`
（`DesignLanguageContract.Verify`）逐变体检查身份、完整、纯净、确定与可读。

新增公开类型：`DesignLanguage`、`DesignLanguage<TLanguageToken>`、`DesignLanguageAttribute`、`DesignLanguageAxes`、
`DesignLanguageBuilder<TLanguage>`、`DesignStyle`、`DesignDensity`、`DesignIdiom`、`DesignVariant`、
`TokenEvaluationContext<TLanguageToken>`、`ControlTokenTarget<TToken>`、`IControlTokenRule<TLanguageToken, TToken>`、
`ControlTokenRuleAttribute`、`LanguageDesignToken`、`LanguageDesignTokenAttribute`、`ReservedTokenAttribute`、
`IControlToken`、`DesignLanguageDescriptor`、`ControlTokenRuleDescriptor`、`GlobalTokenSchema`、
`TokenSchemaDigestAttribute`、`CoversTokenSchemaAttribute`、`ThemeBuildLanguageAttribute`、`ThemeDerivationException`、
`DesignLanguageInfo`、`ThemeSelection`、`ThemeSelectionResult`、`ThemeSelectionResolver`、`ThemeSelectionException`。
`IThemeManagerBuilder` 新增 `AddDesignLanguage`、`AddControlTokenRules`（由生成的注册代码调用，只有自行实现该接口的代码
需要补上）与 `WithInitialTheme`。

自定义 `IThemeManagerBuilder` 还需实现 `WithInitialDesignLanguage<TLanguage>()`、
`SetDefaultTheme<TLanguage>(string)` 和 `SelectValuePackage<TLanguage>(ControlValuePackage)`。
自定义 `IThemeManager` 需实现 `ApplyAsync`、`Languages`、`Themes` 和 `CurrentSelection`。

## Shadcn 与 PrimeNG

`AtomUI.Themes.Shadcn`、`AtomUI.Themes.PrimeNG`（从未发布到 NuGet）由设计语言 `Shadcn`、`PrimeNG` 取代，结构与 Ant Design 相同：

| 语言 | 包 | 风格 | 可调种子 | 入口 |
| --- | --- | --- | --- | --- |
| `Shadcn` | `AtomUI.DesignLanguages.Shadcn`、`AtomUI.Controls.Themes.Shadcn`、`AtomUI.Desktop.Controls.Themes.Shadcn`、`AtomUI.Desktop.Controls.ColorPicker.Themes.Shadcn`、`AtomUI.Desktop.Controls.DataGrid.Themes.Shadcn` | `Vega`、`Nova`（缺省）、`Maia`、`Lyra`、`Mira`、`Luma`、`Sera`、`Rhea` | `ColorPrimary`、语言种子 `BaseColor` | `UseShadcn(language => language.AddDesktopControls())` |
| `PrimeNG` | `AtomUI.DesignLanguages.PrimeNG`、`AtomUI.Controls.Themes.PrimeNG`、`AtomUI.Desktop.Controls.Themes.PrimeNG`、`AtomUI.Desktop.Controls.ColorPicker.Themes.PrimeNG`、`AtomUI.Desktop.Controls.DataGrid.Themes.PrimeNG` | `Aura`（缺省）、`Lara`、`Nora` | `ColorPrimary` | `UsePrimeNG(language => language.AddDesktopControls())` |

两种语言不带具名主题：原来的 profile id（`ShadcnNova`、`ShadcnNova.Dark`、`PrimeNGAura.DarkCompact` 等）已删除，改用
`ThemeSelection.Of("Shadcn", new DesignStyle("Nova")).WithAppearance(ThemeAppearance.Dark)` 等选择；语言自己的条目是
`$Shadcn` / `$PrimeNG`。每个变体与种子用例编译出的
Token 值与原 profile 相同。各包 README 列出规则、来源与不支持清单。

- `ArrowIndicator` 按 antd 的圆角箭头构造（等腰直角三角形，尖端为半径 `ArrowTipRadius` 的圆弧，底边两侧为半径

## 生成注册与启动镜像

同步升级运行时、控件包、取值包和 Generator。清理并重新构建包含启动清单或消费生成注册的项目。
本版更新了启动清单编码和生成的 `PackageMetadata` 辅助类型。使用新构建产物重新发布裁剪、NativeAOT 和浏览器应用，
使生成注册与运行时二进制一致。

## 取值包计算器命名

更新对 Ant Design、Shadcn、PrimeNG 取值包中计算器的直接引用。以 Ant Design Skeleton 命名空间的
`SkeletonTokenCalculator` 替换 `AntDesignSkeletonTokenCalculator`，TreeView 展示层的计算器改用
`TreePresentationLayerTokenCalculator`，然后重新编译消费程序集。
见[取值包命名](../engineering/development/value-package-naming.md#统一命名与重名处理)。

## 控件 Token 覆盖迁移

请把已有主题覆盖移到实际读取该值的控件或界面层。将 6.2.15 的自定义主题和模板升级时，逐项核对以下变化。

- 删除公开标记扩展 `AtomUI.Data.SharedTokenResourceValue`：它在加载时一次性读取应用级值，无法跟随控件级（`Controls[X]`）或作用域（`ThemeConfigProvider`）的动效 Token。请把 `<Setter Property="Transitions"><Transitions><DoubleTransition Property="Opacity" Duration="{atom:SharedTokenResourceValue Kind=MotionDurationMid}" /></Transitions></Setter>` 改写为 `<Setter Property="Transitions"><atom:TokenTransitions><Transitions><DoubleTransition Property="Opacity" atom:TokenTransitions.Duration="MotionDurationMid" /></Transitions></atom:TokenTransitions></Setter>`；仍引用 `SharedTokenResourceValue` 的主题无法编译，ControlTheme 中出现该名称时 ATOMUIGEN041 报告。
- Token owner 注入按注册控件类型精确匹配：注册控件的默认 ControlTheme 带一个嵌套的 `^:OfType(Control)` 样式来设置 `ThemeScope.TokenOwner`，应用子类只有在样式键仍为注册类型（`StyleKeyOverride => typeof(Button)`）时才得到 owner；拥有自己样式键、经 `BasedOn` 复用主题的子类不会得到 owner，需要注册自己的 Token 身份。
- ProgressBar：圆头（`StrokeLineCap=Round`）线形进度的 rail/track/success 圆角改为跟随 `ProgressBar.LineBorderRadius` Token（默认 100），不再是主题硬编码的 `CornerRadius="1000"`；对高度小于 200px 的进度条两者都呈胶囊形，只有设置了 `LineBorderRadius` 的主题会看到差别。`ProgressBar.ProgressActiveMotionDuration` 改为 `TimeSpan`（antd `progressActiveMotionDuration`，默认 2.4s），仍为保留 Token（Active 闪光动画尚未实现）；以数字设置过它的主题 XML 需改写为时长（`00:00:02.4`）。
- ColorPicker Own：19项editor/palette/spectrum/slider字段移到Controls[ColorPickerView] / Controls[GradientColorPickerView]；trigger保留TriggerPadding、TriggerTextMargin、ColorBlockDisabledOpacity、ColorBlockInnerShadows与TransparentBgSize，后两项也由各View独立拥有。旧ColorPicker覆盖不再传入GradientColorPicker或公开View。逐字段迁移见color-picker/token.md；旧无效Alpha字段默认44，新View保持实际原48。
- DataGrid 行、单元格、行头和分组头实现容器的有效全局值与动效时长改随宿主 DataGrid，请经 Controls[DataGrid] 配置；嵌套公开编辑器、选择器、按钮和分页器保持各自作用域。
- LunarCalendar：Fullscreen Year 的选中月份背景使用独立的 LunarCalendar.ItemActiveBg，不再受 Calendar 同名 Own 覆盖；保留月份默认浅蓝色及日期主色。
- Theme Own 作用域独立：DropdownButton、SubmitButton/ResetButton、NumericUpDown、AutoComplete 派生控件、Cascader/TreeSelect、MessageBox、ContextMenu/MenuFlyoutPresenter、卡片/条形页签、SimplePagination、Transfer 视图、TimerStatistic/StatisticCountUp、ImageGroupPreviewer、LunarCalendar、RangeDateViewer 与日期/时间范围选择器均通过实际控件身份配置。原来源控件的覆盖不再传播到其他终端；抽象层只共享计算。SplitButton 的两个公开 Button 与 SearchEdit 搜索 Button 保持 Button 颜色/动效身份。
- Own 键迁移：`Space.AddonBg`/`AddOnPadding*` → `CompactSpaceAddOn`；`Menu.ContextMenuOffsetX/Y` → `ContextMenu`；`Pagination.ItemInputBg` → `SimplePagination`；`DateViewer.PanelSpacing` → `RangeDateViewer`；`DatePicker.RangePanelSpacing` → `RangeDatePicker`；`TimePicker.HeaderMargin` → `DatePicker`/`RangeDatePicker`；`InfoPickerInput.RangePickerArrowMargin`/`RangePickerIndicatorThickness` → 实际 range 控件，`RangeMarginToAnchor` → `RangeTimePicker`。TabControl 的卡片/添加按钮/垂直卡片 padding 键移到 CardTabControl/CardTabStrip；`WindowTitleBar.CaptionButtonCornerRadius` 移到公开标题栏 Button/ToggleButton。仅来源可渲染或 Reserved 的字段不复制到无关终端。
- Mentions/AutoCompleteTextArea 内部编辑器和 TreeSelect 内部树跟随实际宿主；CandidateList 部件使用宿主 globals，不再借用 ListBox Own；TabItem/TabStripItem 动效跟随实际页签宿主。独立公开控件保持各自身份，Dialog surface 在 Window/Overlay 下均跟随真实 Dialog/MessageBox。
- Theme Tokens：删除从未消费的 `WindowTitleBar.ForegroundColor`、`HoverBackgroundColor`、`PressedBackgroundColor`、`CloseHoverBackgroundColor` 与 `ClosePressedBackgroundColor`；请从主题配置移除，按平台/状态改用现有 Active*、Inactive* 与 WindowsClose* Token。ScrollBar / ScrollBarThumb 对继承的动效读取采用 owner 透明语义。
- 展示类主题作用域：TransferListItem / TransferTreeViewItem 与 SpinIndicator 对 Token owner 透明，全局值通过实际视图或 Spin 宿主配置。TreeTransfer 不支持分页，ListWidthLG 保留为 Reserved，普通宽度使用 ListWidth。
- 录入类主题作用域：FormItem / FormItemDecorator、Upload 触发器与拖拽区域、SegmentedItem、CandidateList / CandidateListItem 为 Token owner 透明部件；有效全局值经宿主 Form、Upload、Segmented、Mentions 或 AutoComplete 设置，部件自身的控件级全局覆盖不再生效。嵌套的注册输入框与动作控件保留各自 identity。
- Theme Tokens：删除 Button 家族中没有消费者的 Own Token。请从主题配置中移除 `Button.ExtraContentItemSpacing`、`Button.ExtraContentMargin`、`Button.ExtraContentMarginLG`、`Button.ExtraContentMarginSM`、`Button.GutterToFlyout`、`HyperLinkButton.BorderColorDisabled`、`FloatButton.SquareBadgeOffset` 和 `FloatButton.CircleBadgeOffset`；改用 `DropdownButton.ExtraContentMargin*`/`MarginToAnchor`、`SplitButton.GutterToFlyout` 或 `FloatButton.BadgeOffset`。
- Theme Tokens：`Button.FontWeight` 改为 `FontWeight` 值（`500` 或 `Medium`）并设置 Button 字重；`Button.GroupBorderColor` 标为保留，暂无视觉效果。
- Theme Tokens：各进度控件拥有各自的 Own Token。`ProgressBar.CircleTextColor`、`ProgressBar.CircleMinimumTextFontSize`、`ProgressBar.CircleMinimumIconSize` 移到 `CircleProgress` / `DashboardProgress`，`ProgressBar.ProgressStepMarginInlineEnd` / `ProgressBar.ProgressStepMinWidth` 移到 `StepsProgressBar`（`ProgressStepMarginInlineEnd` 改为 `double` 间距）；`Controls[ProgressBar]` 不再改变步骤、圆形与仪表盘进度条。
- 进度控件：受保护成员 `AbstractProgressBar.StrokeThickness` 更名为 `EffectiveStrokeThickness`（计算值），子类需改用新名称。
- Theme Tokens：CheckableTag 拥有自己的 Own Token `TagFontSize`、`TagLineHeight`、`TagIconSize`、`TagPadding`、`TagTextPaddingInline`，请经 `Controls[CheckableTag]` 设置；`Controls[Tag]` 不再改变 CheckableTag。
- Theme Tokens：删除没有消费者的 `Alert.MessageWithDescriptionMargin`；标题与描述的间距由 `Alert.DescriptionLabelMargin` 表达。
- Theme Tokens：删除从未被消费的 `MessageCard.CardHeight`、`PopupConfirm.PopupMinWidth`、`PopupConfirm.PopupMinHeight`，以及固定尺寸关闭按钮无法体现的 `NotificationCard.NotificationCloseButtonPadding`；请从主题配置中移除。

- Theme Tokens：删除从未被消费的 `Expander.LeftExpandButtonVMargin` / `RightExpandButtonVMargin`（头部随展开方向旋转，`LeftExpandButtonHMargin` / `RightExpandButtonHMargin` 已覆盖所有方向）与 `GroupBox.TextPaddingInline`、`GroupBox.OrientationMarginPercent`、`GroupBox.VerticalMarginInline`（复制自 Separator 的 Token；GroupBox 标题缺口与边距由 `HeaderContentPadding` / `HeaderContainerMargin` 表达），请从主题配置中移除。`Card.ActionsSpacing`、`Card.TabsMarginBottom`、`Card.CardHeadPadding`、`Card.CardPaddingBase`（antd `actionsLiMargin`、`tabsMarginBottom`、`cardHeadPadding`、`cardPaddingBase`）标为保留，暂无视觉效果。

## 性能

字节降到 712,792 字节（-41%），中位耗时由 2.44 ms 降到 1.92 ms。同一作用域的控件共用推导起点的全局视图（推导改写了全局 Token
的控件除外）；只覆盖 Map 或 Alias Token 的局部作用域，对推导没有读到这些 Token 的控件直接复用父作用域的结果。编译结果逐值相同；
明暗切换在本机分辨力内无变化。
