## 结论与实施选择

当前实施：统一 12.1.5，删除 Dispatcher 共享时钟补丁，保留其他仍有用途的 hook。按用户 A6，两个 Wayland
适配删除版本/commit 白名单（含 NWayland），改为安装前只读校验完整成员契约，并保留运行状态守卫与诊断。
原先“更新精确版本门禁”的选择已被 A6 取代，不再作为当前接入策略。总体风险为中等，主要来自 Linux 原生路径
和框架行为变化；成员签名通过不能替代真实平台语义验证。

只改版本会使 Wayland 帧节奏与初始缩放静默退出，并留下已失效的 Dispatcher 私有成员保留声明；不能作为交付。
批量删除原生 hook 则缺少上游等价实现依据，会失去阴影穿透、CSD 或资源回收能力，因此不采用。
用户已在评估交付后明确批准该方案，授权边界见实施记录。

## DataGrid 与安全发布依赖的根因和证据

窄范围审计：`DataGridBoundColumn` 拥有原 Binding 与缓存编辑定义，编辑器表达式按单元格会话创建/释放。
公共 Binding/ClipboardContentBinding、BindingTarget、Source 提交方式、Theme/Token/Gallery API 均不改；
不拆文件、不新增公共类型，不更改调用方绑定 Mode。运行时编辑器无法由静态 ControlTheme 声明这条列定义绑定。

### DataGrid

- 原 `CreateOneWayBinding` 手工 `new ReflectionBinding`，使公共编辑路径静态引入带 RUC/RDC 声明的构造。
  不是只有真正使用反射绑定的调用方才承担诊断。逐项复制还遗漏 `ReflectionBinding.NameScope`、DefaultAnchor 等 XAML 上下文。
- 实际 AXAML 的 `ElementName=Source` 编辑器在原实现抛出 `Cannot create ElementName binding when NameScope is null`。
  CompiledBinding 为同流程对照。修复采用 `System.Object.MemberwiseClone` intrinsic 完整复制已经由调用方提供的定义，
  然后只修改副本 Mode；不生成新反射绑定、不枚举成员、不改原定义、不增加 warning suppression。
- CLR 临时用例：原实现 1 fail/1 pass；修复后 2/2 pass。验证名称作用域、源更新、编辑不提前写回、原定义 TwoWay、
  Dispose 后源变化不再传到编辑器。首次 Dispose 断言错误地要求保留已移除绑定的值，已按框架契约修正并重新取得有效基线。
- 直接链接真实产品私有工厂的 NativeAOT 探针：net10/runtime 10.0.14 和 net8/runtime 8.0.33 各发布/运行 exit 0，
  两侧 `DynamicCodeSupported=false`，副本/原定义身份隔离、OneWay/TwoWay、Source 与转换字段保持均通过。
  这是新复制机制的实执行证据，不是 net8 条件注册后端全能力验收。
- 临时 AXAML/C# 已删除；常驻测试净新增 0。成员检查工具扫描 1 文件（Column 未被其 Control 识别规则计入），
  另人工核对 1 个完整类：公共契约在前、2 个无 initializer 的 runtime 字段后置；无初始化顺序或 API 变更。
