# AtomUI 6.2.15 迁移指南

[English](6.2.15-api-changes.md)

本指南适用于从 6.2.14 升级。版本变更见[更新日志](../../CHANGELOG.zh-CN.md)。

## 快速对照

| 范围 | 6.2.14 | 6.2.15 与迁移动作 |
| --- | --- | --- |
| `IForm` | 原有校验入口 | 自定义实现补齐接收校验选项的异步方法 |
| `AbstractRate.ToolTips` | 共享基类提供 | 改用桌面 `Rate.ToolTips`，或在自定义评分控件中实现提示 |
| 控件基类和模型程序集 | 实现和模型由 Desktop 定义 | 限定桌面文本输入基类名称，更新自定义选择器和属性所有者查找，并扫描共享程序集获取已移动的模型 |
| Carousel 自动播放 | 计时器由桌面控件管理 | 宿主不可用时暂停，如需独立于可见性的切换逻辑，在应用内维护 |
| 列表键盘焦点 | 列表容器或内部元素可能获取焦点 | 焦点落到条目，更新自定义主题和键盘脚本 |
| 生成注册 | 标识包含 6.2.14 程序集版本 | 对齐包版本，重新编译生成注册的消费方并重新发布裁剪或 NativeAOT 产物 |

## Form 校验契约

自定义 `IForm` 实现必须补齐以下方法。现有 `Form` 实例继承 `AbstractForm` 中的实现。

```csharp
Task<FormValidateReport> ValidateAsync(
    FormValidateOptions options,
    CancellationToken cancellationToken = default);
```

按 `FieldNames` 和 `IsSilent` 执行校验，将取消令牌传给校验器，并在 `FormValidateReport` 中返回当前表单值和逐字段结果。
检查通过 `AbstractForm` 调用 `ValidateAsync` 并传递未指定类型的 `default` 的位置。使用 `default(CancellationToken)` 选中原有重载。
以下调用只检查一个字段，并保留当前界面反馈。

```csharp
var report = await form.ValidateAsync(new FormValidateOptions
{
    FieldNames = ["Email"],
    IsSilent = true
}, cancellationToken);
```

检查断言校验文案的测试。未指定提示的校验器使用本地化默认文案，包括 `FormStringNotEmptyValidator`
和 `FormNotNullValidator` 的必填提示。读取
`FormValidateReport.Fields` 或订阅 `SubmitFailed` 可获得结构化的提交失败信息。若自定义实现位于独立程序集，补齐方法后重新编译。

## Rate 提示

`ToolTips` 和 `ToolTipsProperty` 现由 `AtomUI.Desktop.Controls.Rate` 声明。例如，将配置星级提示的辅助方法的参数类型
改为 `Rate`。桌面 AXAML 可继续在 `Rate` 上设置 `ToolTips`。直接派生自
`AtomUI.Controls.Commons.AbstractRate` 的自定义控件可以按需实现自己的提示。重新编译引用旧基类属性或字段的程序集。

## 共享控件基类与类型转发

Desktop Button、Carousel、Collapse、Form、文本、数值、OTP 输入、Slider、Steps、TabControl 和 TabStrip 使用共享基类。
Desktop 保留兼容声明，包括原有 Form 和标签控件的 `DirectProperty` 字段。检查共享样式属性首次注册位置或声明所有者的代码，
请使用目标控件或基类公开的属性引用。重新编译自定义控件，并用升级后的程序集核对属性注册和重写方法。

Form 的 `NotifySubmit`、`NotifyReset`，FormItem 的 `NotifyContentAdded`、`NotifyFormItemChanged`，
桌面 `AbstractTextInput` 的表单与清除扩展点，NumericUpDown 和 Slider 的表单扩展点，以及
`BaseTabControl.RegisterContentPresenter` 改为重写共享基类声明的虚方法。重新编译重写这些方法的程序集，
使虚调用绑定到新的声明。例如桌面 Slider 子类可保留源代码中的 `NotifyFormValueChanged` 重写。

`AtomUI.Controls` 与 `AtomUI.Desktop.Controls` 均有名为 `AbstractTextInput` 的类型。同一源文件导入两个命名空间时，
请使用限定名或别名。

```csharp
using DesktopTextInput = AtomUI.Desktop.Controls.AbstractTextInput;
```

检查自定义输入主题中依赖 `PART_ClearButton` 或 `TextCountIndicator` 的特定父级、同级关系的选择器。
附件控件现在位于附件面板内。按当前层次调整选择器，或使用现有专用 Semantic Part Style。检查复制后仍依赖旧图标
可见性绑定的 Button 和 DropdownButton 模板。

Desktop 按原 CLR 全名转发 Button 枚举、`StepsStatus`、`ICollapseItemData`、`FormItemLayout`、搜索与 OTP 事件类型、
`SliderMark`，以及 Cascader、DateViewer、ImagePreviewer 和 Upload 公开模型。直接引用可继续解析。通过
`Assembly.GetTypes()` 扫描 Desktop 程序集的代码，应从 `AtomUI.Controls.Shared` 获取 DateViewer 类型，
并从 `AtomUI.Controls` 获取其他转发类型的定义。已知具体类型时可通过 `typeof(T).Assembly` 获取定义程序集。

## Carousel 自动播放

轮播控件脱离、隐藏或禁用、动效活动源不活跃、窗口最小化或滑动进行中时，自动播放暂停。
恢复时从新的播放间隔开始计时。如果控件不可用时业务仍需要推进页码，请在应用状态中维护当前页，
用应用计时器更新 `SelectedIndex`。由应用计时器接管时关闭内置自动播放。

## 列表键盘焦点

Tab 进入 ListBox、ListView 和 Transfer 时将焦点落到条目，每次按方向键移动一项。分组 ListView 跳过组标题。
Transfer 通过条目交互改变复选框的选中状态，复选框本身跳过 Tab。默认焦点描边在条目内侧绘制。

键盘自动化应在条目容器上设置焦点并检查选中状态。复制默认主题时，保留条目模板的焦点目标和内侧焦点描边设置。
核对 Tab 进入、方向键上下移动和 Transfer 使用空格选择。

## 生成注册

生成的 `ControlPackageGroup_*` 标识包含所有者程序集版本。将相关 AtomUI 包和 Generator 一起升级到 6.2.15，
重新编译使用生成注册的应用与库。重新发布裁剪和 NativeAOT 应用，让生成注册映射与包注册组标识匹配。
