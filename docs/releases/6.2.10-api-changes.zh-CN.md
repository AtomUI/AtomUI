# AtomUI 6.2.10 迁移指南

[English](6.2.10-api-changes.md)

6.2.10 用直接作用于控件的帧驱动动效替换基于 Actor 的动效库，Windows 默认优先使用 RedirectionSurface，并让窗口型
Popup 的阴影区域对输入穿透。Avalonia 仍为 12.1.4，Release 产品包继续面向 net8.0 与 net10.0。本版本不改变
`build/**`、包布局、SDK 或目标框架契约。

## 速查

| 范围 | 6.2.9 | 6.2.10 / 迁移 |
| --- | --- | --- |
| 动效命名空间 | `AtomUI.MotionScene` | `AtomUI.Animations`；AXAML 的 `atom:` 前缀仍能解析动效类型 |
| 动效契约 | `IMotion`、可实例化的 `AbstractMotion`、`Run`/`RunAsync(BaseMotionActor, ...)` | 抽象 `AbstractMotion`，实现 `Build(MotionBuilder, in MotionContext)`；用 `PlayAsync(Control)` 播放 |
| 动效 Actor | `BaseMotionActor`、`BaseLayoutAwareMotionActor`、`MotionActor`、`LayoutAwareMotionActor`、`IMotionActor` | 已移除；直接对任意 `Control` 播放，展开/收起用 `ContentViewport`，显隐用 `Motion.*` 附加属性 |
| 动效默认值 | `Duration` 300 ms、`Easing` 线性、`PropertyValueFillMode` Forward | `Duration`/`Easing` 可空（取 `MotionDurationMid` Token / 各动效默认缓动），`FillMode` 为 Both |
| 控件动效属性 | `OpenMotion`/`CloseMotion` 类型为 `AtomUI.MotionScene.AbstractMotion?` | 类型为 `AtomUI.Animations.AbstractMotion?`；改 `using` 并重新编译 |
| 模板部件 | `PART_MotionActor`、`PART_ContentMotionActor` 等 | 按控件更名（见下文）；同步更新复制的 ControlTheme |
| Windows 合成 | 优先 `WinUIComposition` | 优先 `RedirectionSurface`；`AcrylicBlur`/`Mica` 需显式选择 |
| 生成式注册组 | 公共 `ControlPackageGroup_*` 名称包含 6.2.9 程序集标识 | 名称包含 6.2.10；同步升级相关包并重新构建预编译消费方 |

## 动效库

### 命名空间

所有公共动效类型由 `AtomUI.MotionScene` 移至 `AtomUI.Animations`，并移除 `AtomUI.MotionScene` 的 XML 命名空间映射。
`https://atomui.net` 本就映射 `AtomUI.Animations`，因此使用 `atom:` 前缀的 AXAML 仍能解析动效类型；C# 需要改用新的 `using`。

```csharp
// 6.2.9
using AtomUI.MotionScene;
popup.OpenMotion = new ZoomBigInMotion();

// 6.2.10
using AtomUI.Animations;
popup.OpenMotion = new ZoomBigInMotion();
```

内置 Fade、Slide、Zoom、ZoomBig、Move、Expand、Collapse 动效保留类名，均新增无参构造函数，另一重载为
`(TimeSpan? duration, Easing? easing = null, FillMode fillMode = FillMode.Both)`。该重载的 `duration` 不再可省略，
`new XxxMotion(easing: e)` 需要为时长显式传 `null`。`MoveXxxMotion.Offset` 与 `ExpandMotion`/`CollapseMotion.Direction`
改为可空、可设置属性；`Direction` 为空时使用目标的 `Motion.LayoutDirection`。

### 动效定义与播放

移除 `IMotion` 与 `MotionSpiritType`。`AbstractMotion` 改为带 protected 构造函数的抽象类，通过 `Build` 描述动效；
原有的配置/通知钩子、动画与过渡列表以及变换辅助方法均已移除。

| 6.2.9 | 6.2.10 |
| --- | --- |
| `IMotion` | `AbstractMotion` |
| `new AbstractMotion(duration, easing, fillMode)` | 派生并实现 `Build(MotionBuilder, in MotionContext)` |
| `ConfigureMotionStartValue` / `ConfigureMotionEndValue(BaseMotionActor)` | `builder.Opacity`、`TranslateX/Y`、`Scale/ScaleX/ScaleY`、`Rotation` 通道配合 `From`/`FromCurrent`/`To`/`KeyFrame` |
| 自定义过渡与动画 | `builder.Property<T>(property, interpolator)`、`builder.Expand/Collapse(direction)`、`builder.Sequence/Parallel(...)` |
| `RenderTransformOrigin` | `Origin`（`RelativePoint?`） |
| `PropertyValueFillMode` | `FillMode`（默认 `Both`） |
| `Duration`（`TimeSpan`，默认 300 ms） | `Duration`（`TimeSpan?`，为空时取 `MotionDurationMid` Token） |
| `Easing`（默认线性） | `Easing`（`Easing?`，为空时取 `DefaultEasing`） |
| `Run` / `RunAsync(BaseMotionActor, aboutToStart, ...)` | `Task<MotionResult> PlayAsync(Control target, CancellationToken)` |

```csharp
// 6.2.10 自定义动效
public sealed class RiseInMotion : AbstractMotion
{
    public RiseInMotion() { }
    public RiseInMotion(TimeSpan? duration) : base(duration) { }

    protected override Easing DefaultEasing => new CubicEaseOut();

    protected override void Build(MotionBuilder builder, in MotionContext context)
    {
        builder.Opacity.From(0).To(1);
        builder.TranslateY.From(8).To(0);
    }
}
```

播放在 UI 线程上直接作用于任意控件。把 `aboutToStart`/`completed` 回调改为 await 前后的代码，并检查结果：
`MotionOutcome` 取值为 `Completed`、`Superseded`、`Cancelled`、`Detached` 或 `NotReady`。

```csharp
// 6.2.9：内容必须包在 MotionActor 中
await new FadeInMotion(TimeSpan.FromMilliseconds(300))
    .RunAsync(motionActor, aboutToStart: () => motionActor.IsVisible = true);

// 6.2.10
target.IsVisible = true;
var result = await new FadeInMotion(TimeSpan.FromMilliseconds(300)).PlayAsync(target);
if (result.IsCompleted)
{
    // ...
}
```

`Motion.IsCurrent(target, result)` 判断结果是否仍属于目标最新一次请求，`Motion.Reset(target)` 取消并复位。
反向请求从当前呈现值连续接续。

### Actor、显隐与展开收起

移除 `IMotionActor`、`MotionActorControlProperty`、`BaseMotionActor`、`BaseLayoutAwareMotionActor`，以及
`AtomUI.Controls.Primitives` 中的 `MotionActor` 与 `LayoutAwareMotionActor` 控件。动效直接写入真实目标的合成层变换通道，
不再有 `MotionTransform` 属性、Actor 的 `PreStart`/`Completed` 事件或跟随模式；`UseRenderTransform` 没有对应项。

由可见性驱动的动效改用 `Motion` 附加属性声明：`IsVisible`、`Enter`、`Leave`、`IsEnabled`、`DurationOverride`、
`LayoutDirection`。需要等待完成时使用 `Motion.GetVisibilityTask(target)`。

```xml
<!-- 6.2.9 -->
<atom:MotionActor Name="PART_MotionActor">
    <Border />
</atom:MotionActor>

<!-- 6.2.10 -->
<Panel Name="PART_VisibilityRoot"
       atom:Motion.IsVisible="{TemplateBinding IsActive}"
       atom:Motion.IsEnabled="{TemplateBinding IsMotionEnabled}"
       atom:Motion.DurationOverride="{TemplateBinding MotionDuration}">
    <atom:Motion.Enter><atom:FadeInMotion /></atom:Motion.Enter>
    <atom:Motion.Leave><atom:FadeOutMotion /></atom:Motion.Leave>
    <Border />
</Panel>
```

布局感知 Actor 改用 `atom:ContentViewport`：内容按自然尺寸排列，视口负责裁剪动画中的占位。自定义布局宿主可实现
`IMotionLayout.BeginLayoutMotion(Direction, bool expanded)`，返回带 `SetProgress(double)` 与 `Dispose()` 的
`IMotionLayoutLease`。

```xml
<!-- 6.2.9 -->
<atom:LayoutAwareMotionActor Name="PART_ContentMotionActor">...</atom:LayoutAwareMotionActor>

<!-- 6.2.10 -->
<atom:ContentViewport Name="PART_ContentViewport"
                      atom:Motion.IsVisible="{TemplateBinding IsExpanded}"
                      atom:Motion.LayoutDirection="Bottom">
    <atom:Motion.Enter><atom:ExpandMotion /></atom:Motion.Enter>
    <atom:Motion.Leave><atom:CollapseMotion /></atom:Motion.Leave>
    ...
</atom:ContentViewport>
```

AtomUI 不再全局注册自定义的 `TransformOperations` 动画器，应用自己对 `TransformOperations` 的关键帧动画改用 Avalonia 默认动画器。

### 控件动效属性

`Popup`、`Flyout`、`FlyoutHost`、`ContextMenu`、`TreeView` 的 `OpenMotion`/`CloseMotion` 及对应 `*Property` 字段，
类型由 `AtomUI.MotionScene.AbstractMotion?` 改为 `AtomUI.Animations.AbstractMotion?`。赋值内置动效只需更换 `using`，
但基于 6.2.9 编译的代码必须重新编译。控件随每次播放请求传入时长，不再修改共享动效对象的 `Duration`。

### 模板部件

复制或重写以下 ControlTheme、或按名称查找部件的应用需要更新部件名。仍使用旧名称的模板会失去动效，而不是接入新的播放机制。

| 控件主题 | 6.2.9 部件 | 6.2.10 部件 |
| --- | --- | --- |
| CountBadgeAdorner、DotBadgeAdorner | `PART_MotionActor` | `PART_IndicatorSurface`（`Border`） |
| CollapseItem、Expander | `PART_ContentMotionActor` | `PART_ContentViewport`（`ContentViewport`） |
| OverlayDialogPresenter | `PART_MaskMotionActor`、`PART_SurfaceMotionActor` | `PART_MaskHost`、`PART_SurfaceMotionRoot` |
| DrawerContainer | `PART_InfoContainerMotionActor` | `PART_Surface`（`Border`） |
| BackTopFloatButton | `PART_MotionActor` | `PART_VisibilityRoot`（`Panel`） |
| FloatButtonGroup | `PART_MotionActor` | `PART_MenuSurface`（`Border`） |
| MessageCard、NotificationCard | `PART_MotionActor` 包装 | 已移除；Frame 本身作为动效目标 |
| NavMenuItem | `PART_ChildItemsLayoutTransform` | `PART_ChildItemsViewport`（`ContentViewport`） |
| TreeViewItem、TreeSelectTreeViewItem、TransferTreeViewItem | `PART_ItemsPresenterMotionActor` | `PART_ChildrenViewport` |

Window 主题新增用于覆盖层内容缓存的 `PART_ContentCacheHost` 与 `PART_ContentBackdrop`。复制的 Window 模板若缺少这两个部件，
覆盖层动画直接渲染，不使用缓存。

## Windows 合成模式

`WithAtomUIDefaultOptions()` 的 Windows 合成模式顺序改为 `RedirectionSurface` → `WinUIComposition` →
`DirectComposition` → `LowLatencyDxgiSwapChain`。只有 RedirectionSurface 由 DWM 与窗口几何同步合成，从而消除 live resize
时的对向边缘错帧与白屏。该模式下 `AcrylicBlur` 与 `Mica` 不可用，`Transparent` 使用旧式 `DwmEnableBlurBehindWindow` 路径。

需要材质效果的应用可在 `WithAtomUIDefaultOptions()` 之后自行配置顺序，并接受 live resize 错帧；同一对象中还需设置应用依赖的其他
`Win32PlatformOptions` 值。

```csharp
AppBuilder.Configure<App>()
    .UsePlatformDetect()
    .WithAtomUIDefaultOptions()
    .With(new Win32PlatformOptions
    {
        CompositionMode = [Win32CompositionMode.WinUIComposition, Win32CompositionMode.RedirectionSurface]
    });
```

## 重新构建生成式注册消费方

生成器把包含版本号的包程序集标识哈希进公共 `AtomUI.Generated.*.ControlPackageGroup_*` 名称，6.2.10 会再次改变这些名称。

1. 将相关 AtomUI 包及显式引用的 Generator 同步升级到 6.2.10。
2. 清理并重新构建使用生成式注册元数据的应用与自定义控件包。
3. 重新发布裁剪与 NativeAOT 应用，使依赖分析使用新的注册组。

不要直接引用生成的组名，也不要把 6.2.9 编译的注册元数据与 6.2.10 包混用。

## 无需 API 迁移的行为变化

- 窗口型 Popup 使用与 Overlay Popup 相同的 `BoxShadowsSecondary` 阴影，其阴影区域在 Windows、X11、Wayland、macOS 上把指针输入
  交给下方内容；打开/关闭动效期间整窗穿透。
- 默认动效时长改为跟随 `MotionDurationMid` Token，不再固定为 300 ms；`ZoomInMotion` 从中心缩放。
- 无放置目标的对话框从面板中心缩放（0.2 到 1）。
- Drawer 与模态遮罩动画期间合成缓存的窗口内容，覆盖层下方内容在动画期间视觉上保持静止。
- Wayland 默认启用帧准备延迟提交；将 AppContext 开关 `AtomUI.Experimental.WaylandFramePacing` 设为 `false` 可关闭。

## 包校验结果

全部 21 个发布包与 6.2.9（net8.0 与 net10.0）比对共报告 142 条诊断，无引用解析失败：

| 诊断 | 数量 | 包 | 原因 |
| --- | --- | --- | --- |
| `CP0001` 类型删除 | 78 | `AtomUI.Core` | 39 个 `AtomUI.MotionScene` 类型迁移或移除（动效库） |
| `CP0001` 类型删除 | 4 | `AtomUI.Controls` | `MotionActor`、`LayoutAwareMotionActor` |
| `CP0001` 类型删除 | 10 | `AtomUI.Controls`、`AtomUI.Desktop.Controls`、`AtomUI.Toolkits.GalleryBase`、`AtomUI.Desktop.Controls.DataGrid`、`AtomUI.Desktop.Controls.ColorPicker` | 随版本变化的 `ControlPackageGroup_*` 注册组 |
| `CP0002` 成员删除 | 40 | `AtomUI.Desktop.Controls` | 类型移至 `AtomUI.Animations` 的 `OpenMotion`/`CloseMotion` getter 与 `*Property` 字段 |
| `CP0008` 接口变化 | 10 | `AtomUI.Controls`、`AtomUI.Desktop.Controls` | `AbstractToggleSwitch`、`AbstractSegmented`、`ComboBoxItem`、`TabControl`、`TabStrip` 将内部接口 `IStateMotionOwner` 换为内部接口 `ITransitionInitializationOwner`，消费方无法引用这两个接口 |

其余包没有 API 差异。以上均为已记录的二进制不兼容：历史 API 比对失败，不添加 suppression，本版本不声明与 6.2.9 二进制兼容。
21 个包的布局均与 6.2.9 一致，无需修改包布局允许清单。与 6.2.9 相同，发布 workflow 以不带历史 API 基线的方式发布这一已记录的
二进制破坏；上述比对作为发布证据保留，包标识、目标框架与构建资产校验照常执行。
