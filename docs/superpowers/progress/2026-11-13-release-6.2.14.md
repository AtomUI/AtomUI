# AtomUI 6.2.14 发布准备

发布源码范围最初为 `v6.2.13..c6820d19b` 的 19 个提交，之后扩展到 `v6.2.13..6a3634f85` 的 26 个提交，补入 Windows 渲染节拍、SDK 11 与 net11.0、Native8 与 ILLink8 兼容修复及 TextArea 修复。前序评审问题的修复、复验和已知边界见[发版前评审问题修复记录](2026-11-11-pre-release-review-fixes.md)。

## 破坏性变更审计

`git log v6.2.13..6a3634f85 --format='%h %s'` 中没有 `!:` 标记。对照实际 API、主题、交互和构建契约后的结论如下。

| 候选项 | 是否破坏性 | 证据与迁移动作 |
| --- | --- | --- |
| Skeleton、Space、Card、Empty、Result（`9b4053ed8`、`8efde53da`） | 是 | Skeleton 基类和 Space 枚举迁出原命名空间，Card 属性字段移到 `AbstractCard`，Empty 描述与 Result 图标的 CLR 和属性字段签名改变，Empty 的描述 Semantic Part 改为 ContentPresenter。Skeleton 自定义模板、缓动线程约束、启停及单独段落默认宽度需迁移。 |
| 焦点与键盘（`94134fe42`、`7e40bc14a`、`fc9f18ae1`、`e42303547`、`af04f9e26`、`9fb2fadc1`） | 是，主题和焦点顺序 | 焦点 Token 宽度及间距键改变，TreeView 与 ComboBox 清除按钮进入 Tab 顺序，部分旧停靠点消失。按需要更新主题覆盖、明确停靠点及自动化脚本。 |
| Picker（`134da957e`、`9fb2fadc1`、`3a9339ddf`） | 是，交互 | 日期和时间输入的 Tab、键入打开、Enter/Escape、焦点离开以及范围确认行为改变。旧键盘自动化须按新提交规则调整。点选时间后提交旧时间属缺陷修复。 |
| Watermark（`9b4053ed8`） | 是，默认外观 | 文本前景默认跟随 owner 的主题，显式设置黑色可维持旧外观。 |
| 主题提交动效（`cf49134c7`） | 是，运行时 | 因主题提交启动的过渡和动画在首帧收束，需长时间切换动效的应用自行调度。 |
| 生成注册组 | 是，二进制 | 类型名包含程序集身份，按 6.2.13 先例同步升级组件和 Generator，重新编译及发布裁剪/NativeAOT 应用。 |
| 启动与主题资源（`f1dbaf362`、`46bc096de`） | 否，按公共契约 | 后台 Prepare 等待点与生成代码实现调整，入口、注册和公开资源查找 API 保持。根主题从当前应用服务作用域解析，验证 AOT 生成与启动。 |
| Dialog、ComboBox、Select、DataGrid、Card（`8128dd8c9`、`6a5fa22b2`、`d1b7e5590`、`4e8bcad28`、`c6820d19b`） | 否，缺陷修正 | 既有控件入口仍可用，修正焦点转交、占位色、清空残留、行拖动滚动及高 DPI 阴影。 |
| SDK、TFM 与包布局（`826ca0919`，#538） | 否，新增 | Release 包新增 `lib/net11.0`，net8.0、net10.0 资产与路径保持；消费方 SDK 要求不变。`global.json` 改为 `latestMajor` 只影响源码构建，打包三个目标框架需要 SDK 11。布局门禁的允许列表原以 `6.2.14` 为键，按基线版本语义改为 `6.2.13`。迁移指南新增“目标框架和 SDK”说明。 |
| Toolchain 与 Generator（`835e3d1e7`、`ab88aeadf`） | 否，缺陷修正 | Native8 不再被包定义静态状态阻断；ILLink8 与桥接恢复对旧版带 `.cctor` 注册承载类型包的兼容。MSBuild 属性、目标和任务参数不变。 |
| Windows 渲染节拍与 Splash（`255147ea2`） | 否，内部实现 | 新增类型均为 internal，仅在 Windows 睡眠计时器路径替换渲染循环计时器，失败时回退。 |
| TextArea（`6a3634f85`） | 否，缺陷修正 | 被父容器拉伸时填满高度，`Lines` 只决定自然高度；未设拉伸的布局不变。 |

依据[发布准备规范](../../engineering/workflows/release-preparation.md)和[6.2.13 迁移指南](../../releases/6.2.13-api-changes.zh-CN.md)，保留历史 API 比对的诊断。已登记的破坏性变更按当前维护分支的 6.2.14 发布决策处理。

## 发布验证

- 全量回归 `scripts/run-full-regression.sh`：6969 个测试全部通过（默认排除 `AtomUI.Localization.IntegrationTests`）。
- 历史 API 比较（基线 6.2.13，逐包打包）：Controls、Desktop.Controls、GalleryBase、DataGrid、ColorPicker 共 105 项诊断，均对应迁移指南章节；按发布规范不加 suppression。比较中发现 Card 属性字段迁到 `AbstractCard` 未写入迁移指南，已补章节与 changelog。
- 正式打包（无历史 API 基线）：21 包通过，目标框架为 net8.0、net10.0、net11.0。
- 包布局门禁（基线 6.2.13）：21 包通过；允许列表键由 `6.2.14` 改为基线版本 `6.2.13` 后 `lib/net11.0/*` 条目全部命中。
- 本机 pwsh 经沙箱代理访问 nuget.org 会断流，门禁需在去除代理变量后运行。
