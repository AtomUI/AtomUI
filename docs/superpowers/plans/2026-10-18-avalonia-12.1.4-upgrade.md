# Avalonia 12.1.4 升级计划与验证记录

> 按用户指定版本执行依赖升级；不创建提交，不扩大到其他依赖升级。

**目标：** 将 Avalonia 12.1.3 升级到 12.1.4，保持 AtomUI 平台接入、主题、控件与消费 fixture 的一致性。

## 源码评估

参考源码按本地优先顺序定位于 `ReferenceProjects/Avalonia`，已执行 `git fetch --tags --prune`。

- 当前 tag：`12.1.3`，commit `8eeda4f6f546165b3f72e63c9f42247abb306905`。
- 目标 tag：`12.1.4`，commit `2d79ba55fae1b1e71c69f93a668080c9029e6a31`。
- 比较命令：`git diff 12.1.3..12.1.4 --stat`、`git log --oneline 12.1.3..12.1.4`，以及相关实现/API 的逐文件 diff。
- 共 131 个文件变化，包含上游测试与基准图。涉及主题共享实例缓存、Button/MenuItem 命令订阅、焦点恢复、Popup 指针定位、TextBlock/TextBox/文本布局、选择初始化、TreeView 选择通知、几何与渲染、Windows 和 Browser 后端。
- `IRenderTarget.RenderTargetSceneInfo` 增加可选平台数据并改变构造/解构签名；AtomUI 未直接使用该类型或已移除的 Win32 `IBlurHost`。`ITopLevelImpl` 的平台场景属性具有默认实现。
- Wayland 新增 AppId；不改变 AtomUI 的后端选择策略。Dispatcher、ManagedDispatcherImpl、Desktop/Wayland 项目文件在两个 tag 间完全一致。
- 上游删除 ImageSharp 测试依赖；框架目标与运行时依赖无需 AtomUI 调整。ReactiveUI、AvaloniaEdit、Svg 等独立发布包保持原版本。
- AtomUI 的 Dispatcher 适配仍精确限制到 12.1.3.0。用户要求移除版本号绑定：以实际后端、闭包和时钟字段校验兼容性，并用 12.1.3/12.1.4 实际包验证。
- 风险为中等：补丁升级覆盖多个 UI 行为，且存在私有成员/AOT 边界；采用编译、临时运行探针、精确筛选测试验证。

## 执行结果

临时共享时钟测试已在 12.1.4 实际包、旧版本边界下运行：3/3 因 `TryShareManagedClock()` 返回 false 失败，符合预期。

更新精确版本边界后，同一临时测试 3/3 通过（85 ms），已删除临时测试及其专用目录。

按用户补充要求移除版本号绑定。跨版本临时宿主在移除前使用 12.1.3 实际包运行，输出 `shared=False; repeated=False` 并退出 1；后续用两个版本复验结构兼容性。

跨版本结构验证：删除版本检查后，链接同一份生产适配源文件的临时宿主在 12.1.3 与 12.1.4 均输出 `shared=True; repeated=True`，且各完成 3 次 DispatcherTimer tick。

解决方案 restore 通过；Gallery Desktop Debug/net10.0 构建通过（0 warning/0 error，83.44 s）；Browser Debug/net10.0-browser 构建通过（0 warning/0 error，21.21 s）。Browser 首次误用 net10.0 导致 NETSDK1005，改用其项目声明的 net10.0-browser 后通过，未修改项目目标框架。

NativeAOT 临时宿主：`dotnet publish ClockProbe.csproj -c Release -r osx-arm64`，链接生产 DispatcherReflectionExtensions 与 FixedMemberReflection，引用官方 Avalonia 12.1.4，未添加私有成员保留规则。首次链接缺少 Homebrew OpenSSL 搜索路径；导入仓库现有 MacOSHomebrewNativeAot.targets 后发布通过。存在 AVA3001 私有 API 提示和 Homebrew 动态库 macOS 最低版本链接提示，无 IL trim/AOT 诊断。实际原生程序输出 `Avalonia=12.1.4.0; shared=True; repeated=True`，三次 tick 在 20/36/55 ms 触发，退出 0。临时宿主及其全部专用产物已删除。

清理后的最终模块验证：
