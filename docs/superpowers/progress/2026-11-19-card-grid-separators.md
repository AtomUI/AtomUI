# Card 网格分隔线与悬停复验

在 `bugfix/shadcn` 的 macOS 原生 Gallery 验证「Customized content」封面和「Grid card」原示例。Grid card 为四列两行、七个格子，含一个禁用悬停的格子和一个留空位置。

网格左侧原先同时绘制外框和格子的内描边，2× 截图显示标题区左框 2 像素、网格左框 4 像素。格子悬停也会把绘制分隔线的五层阴影替换为不同结构的悬停阴影。固定分隔线由网格统一绘制，标题区保有下分隔线，外框由 Card 绘制。格子的悬停底色与阴影使用单独的透明度过渡。

| 验收项 | 结果 |
| --- | --- |
| Shadcn Nova、Vega、Maia、Lyra、Mira、Luma、Sera、Rhea 的浅色与深色 | 16 种外观的封面 Card 和 Grid card 共 32 个场景通过 |
| Ant Design 对照 | 浅色和深色的封面 Card 与 Grid card 共 4 个场景通过 |
| 快速移入移出 | 每个场景 8 次往返，停留时间 22–74 ms。共采样 3,614 个动画帧，内容坐标和指针命中稳定，阴影结构保持一致 |
| Grid card 外框与分隔线 | 左框恢复 2 个物理像素，列线各为 2 像素。悬停时仍有各列分隔线、两行之间的分隔线与标题下沿。留空格子边界保持连续 |
| 恢复静止状态 | 封面卡片的照片与文字区域在悬停前后逐像素一致。快速移出后，网格、标题下沿和外框的受影响区域逐像素复位 |

原生截图使用窗口编号采样，快进快出通过 Avalonia 输入路由驱动，过渡状态通过窗口动画帧回调采样。已查看原生截图和对照图。两版封面卡片验收区域的同状态复拍为零差，能识别 1 DIP 扰动，恢复为零差。网格复位按标题下沿至底部的受影响区域逐像素比较。

临时驱动和截图已清理，取证文件审计通过。清理后在 `net10.0` 运行 Card 单元测试 25 项、Card 网格 1× / 1.5× / 2× 渲染测试 3 项、Shadcn 控件测试 47 项，合计 75 项通过。 `git diff --check` 通过。
