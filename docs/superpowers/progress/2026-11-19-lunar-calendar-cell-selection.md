# 全屏农历日历的悬停、选中与顶部圆角

在 `bugfix/shadcn` 的 macOS 原生 Gallery 打开 Calendar → Lunar Calendar，使用原有 2024 年 2 月数据。复现顺序为先选 8 日，指针移到 7 日，再连续选 7 日和 6 日。

修复前，hover 背景为直角。旧选中格子的圆角和文字颜色先退出选中状态，选中背景仍在过渡，短时出现暗色直角残影。Shadcn Luma 浅色、深色及 Ant Design 浅色分别采到 34、30、14 个这类旧背景帧。

选中与 hover 分别绘制圆角填充，并按日期格的边框厚度内缩。顶部横线保持独立，选中文字和填充同步切换，hover 继续淡入淡出。

| 验收项 | 结果 |
| --- | --- |
| 原始快速切换路径 | 三种外观的旧选中残影均为 0 帧。共采样 173 帧，选中底色与日期、农历文字的颜色同步 |
| 悬停动效 | 同一圆角，三种外观各观测到 38、34、11 个过渡透明度值 |
| 上方圆弧与直线 | 2× 原生截图中，底色从 4 像素高的顶部分隔线下方起弧，整条直线逐像素一致 |
| 布局与选中结果 | 日期格和两行文字的位置固定，最终只选中 6 日 |

通过 Avalonia 指针路由触发悬停和点击，使用 macOS 原生窗口编号截图，使用窗口动画帧回调核对切换过程。复拍与 1 DIP 扰动复位时，日期格区域均为零差，脚本能检测到扰动。已查看原生截图和对照图。

临时驱动与截图已清理，取证文件审计通过。清理后在 `net10.0` 上用 `FullyQualifiedName~AtomUI.Desktop.Controls.Tests.Calendar.` 筛选控件测试，171 项通过。用 `FullyQualifiedName~AtomUIGallery.Tests.ShowCases.CalendarShowCasePageTests` 筛选 Gallery 测试，5 项通过。`git diff --check` 通过。

## 紧凑日期格与 Shadcn 风格复验

原始「Lunar Calendar Card」示例选中 2024-02-08。Luma 浅色旧圆形在「廿九」两侧的 50 个采样点中漏下 9 个，颜色和底色也在快速换日时不同步。小圆角矩形覆盖两行文字，列宽保持原值，日期格高度按两行行高和上下内边距计算。Nova 与 Rhea 深色的中间版本曾在 2× 截图中出现 0 像素的字底空隙。

| 场景 | 原生脚本结果 |
| --- | --- |
| 全屏月份 | Nova、Vega、Maia、Lyra、Mira、Luma、Sera、Rhea 的浅色和深色均通过。保留 4 物理像素的顶部分隔线。圆角风格从线下完整起弧，直角风格保持原造型 |
| 紧凑月份 | 以上各风格使用 6 DIP 小圆角。Shadcn 实测字底留白为 12–16 物理像素，8 日的农历文字侧边采样全部被选中底色覆盖 |
| 快速切换 | 两种布局各 18 种外观（含 Ant Design 浅色和深色对照），共采样 2,548 个动画帧。连续按 8→7→6→8→7→6 激活，文字与选中色同步，旧底色残留为 0，日期和文字位置在同一布局中保持固定 |

已查看原生截图及 Shadcn 矩阵对照图。全屏矩阵复用紧凑专用尺寸调整前的有效结果，并在最终产物上复拍 Luma 浅色和深色。静止复拍和 1 DIP 扰动复位为零差，扰动可检出。

已清理临时脚本和截图，取证文件审计通过。最终清理后使用上节的 `net10.0` 测试筛选运行，Calendar 控件 171 项、Gallery 示例 5 项通过。`git diff --check` 通过。
