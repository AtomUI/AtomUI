# CT-12 / CT-25 原生按钮稳定性专项

用户曾在NativeReadiness性能脚本窗口看到按钮持续闪动；B10已确认原脚本连续交替配置35次，停止后离屏稳定不能证明原生显示面。本专项不重放快速可见循环，不使用Computer Use/系统坐标输入。

1. 外部自驱动引用当前工作树实际程序集，使用Avalonia.Native和实际产品Window，720×660 DIP、11按钮；记录PID、可执行路径、产品程序集路径、平台handle、缩放、实例/状态。
2. ScreenCaptureKit按已验证PID定位该窗口，截图实际OS显示结果；CGPreflightScreenCaptureAccess已读为true。截图不裁剪、对齐、缩放或设置通用容差；保留整个窗口，关闭截图光标不改变UI状态。
3. 固定数据/窗口标题/布局，脚本A稳定→1DIP检错→A恢复→主题B→A恢复，每阶段8帧并等待既有动画结束；帧内不再变更配置，不关闭正常动效。控制与采样用文字握手，单阶段超时自动退出。
4. A/A、B/B及停止更新后连续帧精确比较；1DIP变化应检出；同实例A→B→A校验实际字体、主色和选择，不能以销毁重建恢复。实际显示差异与既有栅格漂移分别记录，不自动称为回归或修复。
5. 查看关键帧，保留文本数值与范围，再删除全部媒体/驱动/编译产物并关闭本次进程。当前Mac原生静止与有限切换证据不外推其他OS、全部交互或所有控件。
