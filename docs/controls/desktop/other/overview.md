# Other 控件

其他类桌面控件文档放在本目录，例如 App、ConfigProvider、Util、BorderBeam 等不直接归入通用、布局、导航、数据录入、数据展示、反馈或窗口分类的能力。

此分类关注跨场景装饰、全局配置、辅助能力和非业务语义控件。控件进入本分类不表示其重要性较低，而表示它不承担某个具体业务交互分类的主职责。
